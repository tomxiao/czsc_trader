# S013阶段四：完整自检与比较

本工作区执行用户2026-10-08“批准进入阶段四”，沿用`codex/s013-research`、S013原数据权限、510500.SH原开发池与研究价格口径。
正式结论以[ASSESSMENT/1](../../../../deliveries/ASSESSMENT/1/report.md)及其精确引用为准；工作区和临时缓存不代替正式交付。

## 约定和方法

- 源候选为[CANDIDATES/3](../../../../deliveries/CANDIDATES/3/report.md)全部10个交接成员，标准场景原四项资格逐项保留。
- [MANDATE/5](../../../../deliveries/MANDATE/5/report.md)仅补全既定60交易日的数值表示，并避免将年度回撤错误映射为全窗回撤硬门。两项年度硬约束由连续账户逐年独立核验，标准SE目标绑定整体年化和频率。
- [事前协议](plan.json)固定每中心8点、11个数值参数的成对联合扰动；保持源码、执行规则、费用及开关。全部80点有独立身份、内容哈希及真实父子派生关系，仅用于自检，无新增登记候选。
- 同一中心按每侧20bp和30bp实际扣费重算，20bp为标准压力配对，30bp为补充；原标准费用为每侧10bp。
- 滚动窗口126交易日、步长21，共72窗；Bootstrap配对平稳区块重采样2000次、平均块长20日、种子13，区间单位为策略相对基准的CAGR差。
- 17成员族矩阵为阶段三正式保留的有偏子集。590次计数含历史510尝试及80新扰动；缺失配置的Sharpe分布与相关性不能由计数补足。族统计不参与候选排序。
- 原始年化与全窗回撤做帕累托分层，同层七项按既定次序比较；原点0、half-even、一般指标0.1个百分点及集中度1个百分点精度。另呈现精度变化与六种相邻优先级交换。
- Q10与Q90为10%及90%分位数。参数退化、滚动超额与成本年化损失为比率差，报告以百分数显示时按百分点解释，均非相对跌幅。Sharpe是收益相对于波动大小的指标。
- 所有诊断保持报告用途；标准中心资格由用户四项硬要求决定，后续阶段与冻结由用户决定。

## 执行与复算

1. `declare.py`发布真实授权、MANDATE/5及完整事前协议；包含不可变交付写入，不直接重新运行覆盖已有版本。
2. `run_batch.py`使用公开TDR准备/完整评价/事实适配/证据发布及Optuna固定队列。`run_remaining.py`按原计划顺序调度，每个新父进程只运行一批，4个spawn工作进程、每进程1原生线程、每请求1线程；遇失败停止，不静默重试。
3. `precheck.py`从已发布的首个完整中心账户检查公共SE与独立七指标复算。`assess.py`从正式发布账户组装全部117个评价坐标，计算五项自检、七项比较、年度四门、已声明行情异常订单影响及独立数值核验。
4. `deliver.py`保存RSCH自编报告与实际证据并组装ASSESSMENT/1，执行FULL确定性复算校验；已有交付保持不可变，后续结论使用新修订。

复算前设置`PYTHONDONTWRITEBYTECODE=1`，`OMP_NUM_THREADS/OPENBLAS_NUM_THREADS/MKL_NUM_THREADS=1`，TEMP/TMP指向仓库根`.tmp/s013-stage3-hfq/tmp`；在仓库根通过既有`.venv/Scripts/python.exe`运行上述相对路径。复算仅针对既有正式输入，新增账户评价须遵守相应研究授权。

完整请求、参数、原始账户、基准、订单、成交、费用、数据与执行身份由正式TDR证据保存；源码及依赖沿用源交付已关联的注册快照。恢复须同时保留S013数据资产、准备引用、登记快照、实验发布证据和交付。仓库根`.tmp/s013-stage4`仅用于过程缓存及日志。

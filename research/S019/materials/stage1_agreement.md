## 1. 已确认目标

交易标的为 MU，单标的只做多、无杠杆，目标仓位为当前策略账户权益的 0% 至 100%。SOXX 可作为行业观察输入。

| 项目 | 中心账户硬门 |
| --- | --- |
| 净年化收益 NAR | ≥55% |
| 净卡玛 Calmar | ≥5 |
| 最大回撤 | ≤25%，且≤同口径 MU 买持最大回撤的80% |
| 常态交易频率 | 完整滚动60交易日闭合交易数中位数≥6笔 |
| 冷清时段频率 | 至少90%的完整滚动60交易日窗口有≥3笔闭合交易 |

用户先提出对标 S018-v1 的收益和卡玛，随后将门槛依次明确为 `NAR>=1.2*45.3017%`、`NAR>=55%`，净卡玛≥5，回撤与频率采用指南默认。本稿使用最终确认的固定55%，取代前面的相对倍数。

决策周期下限为30分钟，上限为日线。持仓可以跨日，周期组合由研究问题决定。首轮优先比较日线与30分钟两个端点；其他周期涉及的数据产品和交易时钟能力在使用前核验。

达标且证据可比的候选优先按中心标准费用下 NAR 降序排列。建议使用未舍入值，完全相同时并列，ID仅稳定展示顺序。卡玛超出5的幅度、回撤和交易频率另行展示，排序优先级保持本次已讨论方向。

## 2. 统一统计与执行口径

建议初始资金100,000美元，每侧费用为成交额的0.1%，额外滑点为0。研究观察、回放成交及估值使用DFLS后复权价格，数量为整数模拟单位，最小数量1，价格步长0.01美元。复权效果留在价格序列，账户按当前V4合同记账。

NAR按完整连续账户期末权益与初始权益、实际评价交易日数和252日年化基准计算。最大回撤包含初始权益，使用每日常规交易时段结束后的连续账户净值，跨年延续历史高点。Calmar为该NAR除以正的最大回撤幅度，使用未舍入值验收。零回撤、非有限值或数据缺失时，Calmar验收标为待定并披露原因，保留原值供核验。30分钟收盘采样回撤另报，说明其采样范围。

闭合交易按实际退出交易日归属，窗口前入场且窗口内退出计入。期末持仓保留估值和未闭合状态。60日窗口逐交易日移动，仅用完整窗口，覆盖率以达标窗口数除以全部完整窗口数计算。新增K线数量、重叠事件及窗口分别统计其依赖关系。

沿用已讨论的S018-v1执行条件作为比较底稿。买入限价为最近可见收盘价上浮1%，按最小价位向下取整，严格触价，卖出使用市价，卖出款使用 `IMMEDIATE_RESEARCH` 研究假设。它覆盖早期草案提出的0.5%溢价及交收后可用建议。实际券商现金约束在进入模拟交易前另行核验。

按纽约时区、常规交易时段及真实交易日历组织，完整K线形成且到达声明可用时点后决策。日线在下一交易日执行，30分钟信号在下一可执行区间执行，收盘信号跨至下一交易日。订单按公开EC合同在下一执行柱有效，未成交记为过期，后续按新决策处理。供应商数据暂采用柱收盘可用的研究假设，并保留历史发布时间及修订缺少独立证据的限制。

基于柱范围的成交保留开盘成交或区间触价的区分。缺失行情、零量、停牌及动态交易事实须在正式准备时逐项核验，缺口处理政策在使用前列出依据和适用范围。

MU买持是可投资基准，采用同标的、同窗口、同初始资金、同费用、同复权与数量口径及同执行合同。每一种决策周期固定自己的可执行买持合同，再开展该周期账户比较。跨周期展示同窗结果，并披露订单有效区间导致的执行差异。

## 4. 新增稳健性建议，待确认

中心目标按第1节执行。为了给性能退化保留清楚、易审阅的限度，建议局部扰动及费用压力采用NAR≥50%、Calmar≥4.5。相对中心门槛分别容许5个百分点和0.5的下降，具体数值是本轮RSCH提出的批次约定。

| 场景 | 建议验收条款 |
| --- | --- |
| 参数扰动联合条件 | 对事前固定完整合法局部邻域的N个非中心配置，至少ceil(13N/16)个同时满足NAR≥50%、Calmar≥4.5、回撤≤标准费用买持回撤的90% |
| 参数扰动绝对风险 | 全部N个配置回撤≤25% |
| 费用压力 | 每侧费用提高至0.2%，固定中心规则与参数，重算策略及同条件买持。策略NAR≥50%、Calmar≥4.5、回撤≤25%且小于压力买持回撤；压力买持回撤为0时要求策略回撤也为0，并如实处理Calmar不可用状态 |

邻域尺度、整数合法步长、边界、整项不适用及失败状态采用[RSCH指南附录A/B](../../RSCH_AGENT.md#research-policy)。默认各参数局部相对变化上限5%，联合通过比例13/16，全部配置有效且等权；缺失及技术失败保留在固定点集中。确认整项不适用时按指南记录。频率硬门用于中心标准账户，邻域及压力另报频率。

五项自检包括参数敏感性、时间稳定性、收益集中性、执行敏感性和统计不确定性。中心与邻域的全部目标共同核验。相对绩效区间围绕NAR及Calmar分别解释，重抽样保留时间依赖；选择偏差方法需对应实际按NAR排序的过程，并披露Calmar等硬门筛选。根据实际样本、研究族和计算对象确定方法，事前留证。

## 5. 首轮研究问题及推进依据

起始经济假设是行业共同预期变化与MU特有变化的价格吸收速度可能不同。若有一部分调整在可执行入场后继续发生，可以发展参与该部分调整的仓位函数。竞争解释包括一次性跳空已完成定价、持续调整，以及短时流动性冲击后回撤。判断依据来自后续路径、实际成交、成本与持仓占用。

1. 收益和主要损失在隔夜、开盘后首30分钟及其余常规时段各如何形成？日线先支持隔夜与全日拆分，30分钟数据准备就绪后再细分首段。
2. 使用上一完整交易日信息入场，与等待首30分钟信息后入场，各自付出多少价格变化、错过多少机会，又减少多少损失？比较成交前与成交后部分，使用相同的信号日期集合及实际限价条件。
3. 行业共同变化与MU相对变化对后续收益、损失和持续时间分别有什么信息？比较无条件、MU自身、行业、联合解释，并保留互补组与反例。行业敏感度只使用当时已可得的历史估计，尺度由本研究问题确定。

首轮拟观察1、5、20个交易日三个期限，短端增加次一30分钟与当日余段，在各自可执行时点统一定义标签，未成交事件独立计数。这些期限承担机制辨别职责；后续原型的持有和退出依据随研究结果发展。

优先共享同一套数据、日历、特征和标签。对完整账户有辨别价值时，在获批阶段二内形成包含入场、仓位、持有、退出的简洁原型，并设置可执行简单基线和必要对照。结果只集中于成交前、费用后消失或主要依赖个别事件时，先说明其对原假设的影响，再决定停止或换问题。工具和实验顺序由RSCH按问题选择。

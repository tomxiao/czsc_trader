# 阶段三恢复前的既有路径诊断

本次只读取 C0300、C0224、C0135，以及与 C0224 其余参数完全相同的 ATR=2.28（C0256）、ATR=2.52（C0259）五份既有账户，新增账户 0。复用公共 `read_account` 校验引用及账户材料哈希，使用 pandas/NumPy 做对齐和描述统计。样本保持 2022-01-03 至 2026-10-30，标准费用每侧 0.001。

## MDD路径与贡献

C0135、C0224、C0259的MDD均从2026-10-07高点延续至10-30样本末端；C0300的最差段转为2026-02-02至02-10，02-27恢复前高。ATR收紧的C0256最差段为2022-11-30至2023-04-25，05-26恢复。

按周期账本净盈亏除以该周期入场前账户权益，C0300相对C0224最大的变化为：

- 2026-05-19至05-27：增加约19.69个百分点账户权益贡献。C0224在同一段相对C0135少约19.68个百分点，C0300在此恢复了较高的上涨参与。
- 2026-02-02至02-04：减少约4.03个百分点贡献，体现增配同时扩大了这次亏损。
- 2025-03-07至03-14：增加约2.70个百分点贡献。
- 2024-10-10至10-17：增加约1.37个百分点贡献。

这些是给定账户路径的配置贡献描述。周期净现金盈亏还受前期复利影响，因此比较时统一除以入场账户权益，并另外保留可加的逐日对数增长差。C0300相对C0224，前10个差异日占全部绝对日对数收益差48.84%，提示近期少数强上涨路径对改善贡献较大。

## ATR敏感性集中在哪里

ATR从2.4降到2.28，四个共同入场周期的退出提前：2022-08-18入场、2022-12-12入场、2023-03-31入场、2025-11-19入场；另有2个仅收紧版出现的入场、1个仅中心版出现的入场。最后一项从2025-11-26退出改为11-21退出，周期归一化贡献少约8.34个百分点；2023-03-31入场段少约2.51个百分点。全样本前10个差异日解释87.02%的绝对日对数差。

ATR从2.4升到2.52，117个入场保持一致，仅6次退出变化。影响最大的是2026-10-06入场段：从10-12退出延至10-13，周期归一化贡献少约2.77个百分点；2024-07-24入场段多约1.18个百分点；2026-02-02入场段少约0.64个百分点。前10个差异日解释90.73%的绝对日对数差。

退出时点使用 `cycle_id → fills → order_id → decision_id` 精确关联。个别周期记录结束时间与最后实际成交时间不同，JSON同时保留记录时间和实际成交时间。股数、再平衡成交量、前期复利导致的规模差异未计作新的入/退场择时；入场和退出的真实成交时点及相应退出原因逐周期保留。

## 对下一轮优化的含义

1. 优先联合搜索参与阈值、quiet_fraction与weak_fraction，检验能否兼顾上涨参与和亏损段仓位。现有9个全部原中心硬门通过点均为ATR2.4：threshold1.25/quiet0.5225一簇，以及threshold1.1875/quiet0.55或0.5775两簇，各含三个weak配置。weak的微调作用较小，threshold和quiet更直接改变收益风险取舍。
2. ATR继续进入联合搜索，但解释重点放在少量离散退出变化，尤其2025-11、2026-10的持有与提前退出取舍；最高点附近的小数优化应结合更广参数区间及后续稳健性证据判断。
3. JSON保留了C0224同结构81份旧观察（80个自检点加中心），每项含实际参数、内容身份、原账户引用、原六项门和绩效，可供Optuna热启动。9个中心达标点是阶段四观察后形成的阶段三线索，本次继续使用同一已见开发样本。

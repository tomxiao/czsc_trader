# EX044：MU／SOXX 后复权输入核验与行业信息探索

用户已批准增加SOXX日线，进一步同意MU与SOXX研究信号统一使用含分红后复权价格，正式成交与MU账户继续沿用原始价格和原公司行动记账。该批准没有改变交易标的、开发窗口、D、硬约束或阶段，也没有授权平台修改。

本轮取得并核验两标的行情，完成行业共同变化与MU相对变化的描述性比较，定位两个平台接入问题。没有新增策略账户，没有达标或阶段推进结论。30轮额度累计使用11轮，剩余19轮。

## 1. 数据与复权口径

使用已安装Futu SDK 10.10.7008的只读行情连接，取得MU后复权、SOXX原价与后复权日线；MU原价复用冻结C6300输入。各序列覆盖2022-01-03至2026-10-30，共1212个完整日线、其中961个开发池交易日，日期完全一致，成交量均为正。全部分页完成，原执行数据没有替换。

SDK的`AuType.HFQ`在这两个标的的实际返回中包含现金分红调整。逐事件复算采用：

`P_hfq = A * P_raw + B`

从历史起点A=1、B=0开始，按生效日处理每个事件的后复权因子a、b：先`B <- B + A*b`，再`A <- A*a`。只使用不晚于当前行情日期的事件。2022之前的事件仅用于确定预热开始时的累计复权基准，没有读取此前行情用于研究。

|核验|MU|SOXX|
|---|---:|---:|
|预热起点累计A|2|1|
|预热起点累计B|0.4|20.37054|
|截止日累计A|2|3|
|截止日累计B|4.95|41.19790|
|窗口内事件数|19次现金分红|19次现金分配、1次拆股|
|1212根OHLC最大复算误差|约1.0e-9|约1.0e-9|
|物理历史前缀检查|33次通过|33次通过|

SOXX在2024-03-07的一拆三使原价收盘变化约-65.52%，后复权变化约+3.29%；机械跳变已被处理。窗口内每个事件还通过“无市场变化时应保持连续”的代数核验。MU后复权可从原冻结OHLC全部重建，在1e-5容差下未发现旧执行行情修订。

这一口径是累计现金加回，不是现金分红再投资的总收益指数，不能把后复权涨幅当成正式账户收益。SOXX仅作为研究参照，无须为它建立真实持仓和分红支付账本；配套复权记录用于验证研究价格口径。

时点边界：供应商返回的是当前历史快照，数学重建只使用截至当日已生效事件，避免纳入未来生效事件。尚无逐日公告版本档案，不能声称已独立验证全部历史发布时刻；事件在生效会话已可得、日线收盘可用属于研究假设，与真实到账时点区分。

## 2. 行业信息的初步用途

在看到分组结果前固定分析方案：用截至t-2的60个交易日估计MU对SOXX日收益的敏感度beta，将随后两日MU变化分成`共同项=beta×SOXX两日变化`和`相对项=MU两日变化-共同项`。在后复权两连跌机会中，比较两个负向贡献哪一个占主导。beta仅使用当时过去数据，未按收益调切点。

事件收益复用EX039全部可成交机会的正式价格、费用及分红标签。后复权两连跌的闭合事件仍为201个，与原标签中的两连跌集合相同；不是新策略账户，也不假设重叠事件可以同时全仓参与。

|回落来源|事件数|1日平均净收益|3日平均净收益|6日平均净收益|3日尾部5%|
|---|---:|---:|---:|---:|---:|
|共同下跌贡献占主导|109|0.465%|1.529%|2.690%|-6.400%|
|MU相对下跌贡献占主导|92|0.102%|0.722%|1.577%|-7.734%|

三日期限，共同下跌占主导组在2023、2024、2026年优于相对下跌组，2025年略低（1.631%对1.691%）。六日期限并非逐年同向，因此不能说所有期限都稳定占优。另一个解释组——行业共同项非负但MU相对项为负——44个机会的三日平均净收益仅0.021%。

初步认识：行业上涨而MU自己下跌，并未自然产生更好的修复机会；部分随行业共同回落的机会反而更容易修复。值得进一步区分共同冲击后的修复与个股自身走弱，但该统计还不能证明金融因果，也不能说明在频率约束下能形成更好的完整账户。SOXX可能含MU本身，相对项不等同纯企业特异冲击。所有结果都来自已见开发池，非独立验证。

## 3. 正式接入的两项问题

### DFLS复权参数大小写缺陷

直接SDK使用`AuType.HFQ`（值为`hfq`）成功返回两标的各1212根行情。公开DFLS准备结果为PARTIAL：两标的SESSIONS均READY，BARS均失败，尚无完整PreparedDataRef。

离线SDK请求打包已定位：现有适配器将BACKWARD映射为`HFQ`、FORWARD映射为`QFQ`，SDK合法值是`hfq`、`qfq`、`None`。大写返回-1及`autype is HFQ, which is not valid`；小写成功生成请求。此探针禁止网络连接，证明是本地参数映射问题，不需要猜测供应商权限或网络故障。直接SDK默认session=N/A、DFLS为RTH，两种值均通过SDK校验；修复后仍应核验实际日线结果一致，不能据离线检查声称已等价。

### V4研究行情与执行行情尚未分离

当前`EquityAuxiliaryInput.analysis_price`只接受RAW，辅助输入只绑定BARS与SESSIONS，并禁止重复声明主标的同频率行情；主策略的analysis_price也只接受RAW。因此不能直接把MU／SOXX含分红后复权输入用于正式V4账户。

`ctx.events`只包含MU交易账户已记账的事件，没有SOXX事件，也没有完整的每股分红与预热期事件视图；空仓时应收变化为零，不能从它可靠恢复研究所需的全部复权信息。

未修改平台，没有把HFQ伪装为RAW，也未通过代码常量、参数表或文件查询注入事后信号。原价回测仍保持原合同。

建议在当前分支完成以下支持后，由RSCH继续剩余19轮阶段二研究。

|范围|具体改变|必要核验|
|---|---|---|
|DFLS Futu参数映射|FORWARD/BACKWARD使用SDK合法的qfq/hfq；NONE不变|严格SDK参数校验；现有原价、分页、半日市及失败测试；两标的真实准备从BARS失败变为READY|
|独立研究行情声明|允许显式声明含分红后复权研究序列，分别用于MU与SOXX；MU自身复权辅助序列须与原价执行主序列有不同输入身份，避免放松所有重复检查|RAW与BACKWARD混用被拒绝或明确分工；辅助别名、频率、来源及复权口径唯一；原策略默认行为不变|
|准备身份与时点约束|将价格调整类型、来源修订、含分红定义、复权基准及可用时间依据纳入准备/审计身份；仅向策略提供决策时点可见研究历史|历史前缀与事件生效截断一致；未来事件不能改变此前研究输入；缺失或不一致显式失败|
|TDR/SRT到执行的分工|策略从独立研究视图形成目标仓位，订单、股数、触价、费用及权益继续使用原价主数据|MU/SOXX因果输入核验；无变化控制策略的原价成交和连续净值一致；不重复计分红|

优先实现独立研究行情视图，避免为SOXX建立不需要的交易权益账本。不能只删除RAW检查就宣称完成。接口字段和实现由DEV在上述业务边界内确定；不扩大到生产、部署、搜索、阶段三或新标的。

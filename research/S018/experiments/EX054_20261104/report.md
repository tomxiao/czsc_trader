# EX054：行业卖压持续性用于入场风险预算

32个正式账户完成，29个配置满足原全部经济与频率门槛，但未形成值得替代C8214的持续下跌改进。原D最高C8409净卡玛4.764，略高于C8214的4.748；其变化仅为两笔交易减半预算，十月主损失仍全额参与。达标事实、原D排序及全部负面结果保持，不将这一微小局部改善描述为已识别持续下跌。停止静态入场CUSUM减仓路径，继续以C8214作为固定研究对照。

## 1. 问题、竞争解释与原约定

用户批准以C8214为新基线，继续阶段三研究持续下跌表现。C8214用行业共同贡献分类配置100%/37.5%的入场现金预算，三日开始检查修复、第五日最迟发退出决定。行业分解说明回落来自哪里，未说明卖压将持续多久。

本轮竞争解释是：一是累积负向行业变化代表仍在持续的重新定价，修复交易应减少资金风险；二是累积卖压已释放较多风险，正是反弹收益较集中的区域，过早减仓会削弱收益。所有风险状态仅依据决策时已完成的行情，没有把事后下跌标签用于入场。

原开发池2023-01-03至2026-10-30、2022预热，MU/SOXX HFQ观察、MU RAW执行和公司行动计价保持。初始10万美元，每侧0.1%费用、前收盘1.01限买及市卖、整数股、只多不杠杆、研究即时现金合同不变。D仍为净年化/最大日净值回撤：D至少同合同买持的1.5倍（2.930618）；回撤≤25%且≤买持80%；完整60日闭合中位≥6、至少3笔覆盖≥90%。十月和其他下跌路径用于诊断，不另设验收门。

## 2. 状态表达与方法来源

令SOXX日对数收益为s，z_i=s_i/std(s[i−20:i−1])，标准差只用该收益之前20个日收益。最近40个z从H=0递推H_i=max(0,H_{i−1}−z_i−k)。lag=0包含最新完整交易日，lag=2将观察终点退后两日，区分此前压力与触发入场的两日回落。若H≥h，则把C8214原入场预算乘以risk_scale；这一调整只作用于新入场，持有后不再调仓。

方法借鉴[NIST CUSUM控制图的单边累计偏离递推](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc323.htm)。本实现采用有限40日重置和随时间变化的波动归一化；金融收益不满足标准工业过程假设，未校准报警概率、漏报概率或显著性，不把H解释为持续下跌概率。

正向CUSUM域为k=.25/.5、h=2/4/6、lag=0/2、风险态预算乘.25/.5，共24点。增加2个反向风险配置（低分区减仓）、3个统一比例配置、2个仅单日下跌冲击配置及1个无风险调整控制，共32点。单日冲击为最新s除以前20日标准差的负值，区别于累积状态。其他C8214参数完全固定。

## 3. 全池诊断、机会代价及十月结果

### 3.1 基线提示风险方向并非显然

C8214共94笔闭合，其中10笔交易净收益低于−5%，6笔来自共同组、4笔来自其他组。共同组入场前SOXX10日收益为负的41笔，26笔盈利、均单净收益4.49%；非负19笔仅9笔盈利、均单1.29%。这不是可执行组合对比，却说明行业持续下跌也容纳了重要修复机会。

2025-01-24的−14.98%交易前，SOXX的2/5/10/20日收益均为正。2026-10-12的−13.21%交易前，SOXX5/10日已为负，但20日仍为+6.04%。长趋势过滤无法统一解释这些损失。前笔亏损后三个交易日内重入的21笔中有13个赢家，包括2026-03-09的+22.34%及2025-08-04的+17.75%，所以失败后直接禁入也不是无代价方案。

### 3.2 低门槛主要削减了赢家

k=.25、lag0、h2时，26次入场预算改变，包含18个基线赢家和8个输家；乘.25的C8400卡玛降至2.597，乘.5的C8401为3.300。h4只改9笔，却有8个赢家、1个输家。lag2、k=.25、h2改15笔，其中13个赢家、2个输家。单日冲击阈值1的C8429减31笔（20赢、11输），卡玛2.613，同样没有支持简单“跌得更多就减仓”。

C8409（lag0、k=.5、h4、乘.5）卡玛4.764，仅对2024-04-22的+5.56%赢家和2025-04-04的−6.49%输家减半预算。C8405（lag0、k=.25、h6、乘.5）卡玛4.753，则只额外削减2024-08-05的+0.77%赢家。极少量交易带来的微小D变化，没有形成广泛下跌改进的依据；两点仍按原门槛保留达标记录。

### 3.3 高门槛未改变入场是真实数据结果

lag2、k=.25时，961个决策中的H最大8.7153，但94次实际入场最大仅3.9298，故h4/h6对入场预算无作用；lag2、k=.5实际入场最大2.6850。lag0、k=.5全日最大6.1183，实际入场最大5.1340，h6没有改变入场。高分可能发生在已有持仓或未成交时，不能把“无实际预算变化”误写为“风险状态在所有日期从未触发”。

分数分布同时保存全部决策、219次入场合格信号和94次实际成交三个层级。lag2、k=.25、h4反向减仓的C8425因此在所有实际入场都减半，其汇总指标与统一半预算C8427相同，卡玛4.290、回撤7.53%；这体现统一减少风险，而非额外识别能力。

### 3.4 十月主损失全部漏过

10月6日的原预算37.5%、10月12日的原预算100%在所有正向CUSUM配置中均未降低。10月12日前分数为：lag0/k=.25=1.4853，lag0/k=.5=.7456，lag2/k=.25=.2397，lag2/k=.5=0，全部低于本轮最低h2。10月2至15日仍亏约13.12%。部分配置的美元亏损更小，是此前收益降低后资金规模变小，不是这两笔交易的风险预算得到保护。

### 3.5 路径解释的限制

逐笔分析保存削减赢家与输家的次数、原交易收益、实际美元盈亏和预算加权交易收益描述。实际美元差异包含此前资金路径，预算加权收益和逐笔收益求和不等于复合账户收益，不作为隔离因果估计。EX047已有反证同样保留：C7502提前失效退出改了44笔，其中23笔原本最终盈利、10笔变为非正收益，卡玛从4.164降至0.880。不能将“前两日尚未修复”直接等同应该退出，更不能把信号日价格锚点误认为实际成交成本线。

## 4. 研究决定与下一轮

停止把静态入场CUSUM高分直接映射为低预算的路径。最低h2已显著削弱原D，降低k使状态更易触发，却没有表现出改善趋势；高门槛的最佳值靠近完全不动作的控制。降低h有覆盖十月主损失的技术可能，但缺少能抵消误伤反弹的依据，不专为命中已见区间继续向下细调。本轮没有声称所有行业持续性信息都无效，只否定当前这一资金映射的继续投入价值。

下一轮EX055研究入场后能否通过实际修复证据逐步承担风险：初期仅投入原预算的一部分，修复后再补足，与不补足的统一低预算、直接全预算及相反补足条件同时比较。问题从“入场前是否已知道未来卖压持续”转为“在信息逐步出现时如何分配资金”；继续保留三日试探和原五日上限为对照，不以避开十月为唯一目标。新增表达须明确加仓时点、资金上限和实际成交，仍使用正式完整账户。

## 6. 执行与校验

32个正式账户全部SUCCEEDED，4工作进程、每进程1数值线程，共用1个输入快照及1个同合同买持。全部决策观察截止早于执行区间。独立只读脚本从完整SOXX历史前缀重算32×961=30,752个CUSUM分数，全部吻合。所有94笔入场/退出时序均与C8214相同；C8431的成交、日账本、交易、公司行动及全部汇总指标逐经济字段精确复现C8214。

本轮为30轮授权中的第21轮，剩余9轮；没有新增外部市场数据、平台修改、阶段四或生产行为。全窗口为已见开发池，参数相关性与跨阶段选择偏差保持。NIST仅用于方法来源，不构成新增交易数据。

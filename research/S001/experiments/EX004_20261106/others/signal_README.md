# S001 完整周纠偏：前瞻窗口信号控制对照

两版在 2026-09-02 至 2026-11-05 的 41 个信号日中，partial 与 complete 的周离散因子、分数、市场状态和目标仓位均零差异。前 40 个信号对应 9/3 至 11/5 已结算执行窗口；11/5 信号对应 11/6，单独标记未结算，两版目标均 0。

## 方法

从 2020-11-16 canonical 历史起点计算。对每个信号日独立构造全部当日可见周输入，再计算整段 factor_score、regime、_positions，最后取当日目标。旧 partial 语义保留过去已完成周，只附加当日收盘时尚未完结的当前周尾柱；新 complete 语义仅保留由交易日历确认已完成的周。没有把逐日末尾分数拼成状态轨迹。

日线与 30 分钟 CZSC 输出在 9/2、9/30、11/5 三个前缀逐值核对后共享缓存；周信号对每个实际输入前缀重新生成。新完整周逐日前缀结果还与完整周全历史结果的相同前缀逐值相等。两版原冻结纯数学函数和配置与迁移副本逐 AST 比较一致；文件 SHA 见 summary.json。

原生 step 使用相同完整周可见输入，分别核对 82 个信号日的 factor_score、regime、signal_target 和目标，全部一致；这里以充足现金的空账户隔离信号，完整账户与生产订单比较由主会话另行完成。

9/30 虽为周三，但该周后续国庆休市，计为已完成周；11/5 当周仍有 11/6 开市，剔除 11/5 尾周。不能用机械周五规则代替交易日历。

## 可用材料及边界

四份全量 CSV 为 v1-complete.csv、v1-partial.csv、v2-complete.csv、v2-partial.csv，字段统一 Date、factor_score、regime、target_position；逐日联合表见 daily_signal_comparison.json/csv，引用与验证元数据见 summary.json。

这是利用 11/5 已留存 canonical 数据建立的受控反事实，不等同于逐日原供应商快照逐字回放。当前未完周用当日之前的后复权日线聚合，过去周直接使用留存周数据。历史修订、真实发布时间及实际 PTE 决策的一致性须用另存的生产链条核对。本窗口信号完全相同仅表示这 41 天未触发周离散因子的差异，不能推导全部历史、新旧实现在所有行情下一致。

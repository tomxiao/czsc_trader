## 经济目标、频率与稳健性

本批次拟完整采用[共同默认政策](../../../../RSCH_AGENT.md#research-policy)，不降低美股门槛。机器契约保存在同目录`contract_v2.json`中，确认状态如实区分。

| 验收项 | 条件 |
| --- | --- |
| 净年化 | 同口径buyhold净年化>0时，策略≥其1.5倍；否则策略>0 |
| 相对回撤 | 策略回撤幅度≤buyhold的0.8倍 |
| 绝对回撤 | 策略回撤幅度≤25% |
| 常态频率 | 全部完整滚动60交易日窗口的闭合交易数中位数≥6 |
| 冷清时段频率 | 至少90%的完整滚动60交易日窗口有≥3笔闭合交易 |
| 参数邻域 | 适用参数按业务合法步长，在中心±5%内事前固定完整联合邻域；N>0时至少ceil(13N/16)点同时满足：正buyhold时年化≥1.25倍，否则年化>0；回撤≤buyhold的0.9倍；全部N点回撤≤25% |
| 费用压力 | 每侧0.2%时，策略净年化>0且>压力buyhold；策略回撤<压力buyhold且≤25%；压力buyhold回撤为0时允许策略回撤为0 |

全部适用硬条件同时满足，不允许高收益抵消回撤或频率失败。参数组确无合法非中心组合时，按政策记录不适用，不伪造通过；技术失败不缩小分母。
以**30分钟收盘采样净值最大回撤（BAR_CLOSE）**作为全部回撤验收口径，同时报告日末回撤。完整账户连续计算，包含初始现金，不按年重置最高净值。
收益按252交易日复合年化，费用已经扣除；初始资金、时间与基准一致。闭合交易按实际退出日归属窗口，跨窗口入场而在窗口内退出计入，未退出不计；重叠窗口不作为独立样本数。

## 必报诊断及排序

逐年及滚动252交易日、步长21交易日检查收益、回撤和超额收益；自然年统计继承连续账户，首尾不完整年份如存在则标为部分年份，不外推成年化年度事实。开发池按2019—2025完整自然年报告，不按有利年份筛选。
“连续落后”定义为连续滚动窗口内策略净收益低于同窗口buyhold净收益，报告连续窗口数、涉及日期及差额，不设置额外淘汰线。
收益集中性使用MAX_SINGLE（最大单笔盈利占盈利总额），并报告未平仓对评价的影响；没有足够闭合交易时记不适用或证据不足，不填零伪造低集中度。
报告超额收益区间、研究族选择偏差及所用方法假设；统计结果只作诊断，不另设PBO或DSR硬门。后续检验的具体抽样方案在相应实验开始前留证。
缺失、零量、已知中断、陈旧估值、抑制信号及受影响订单数量分别报告。未计算的影响保持未知，不用K线数量代替订单数量。

达标且证据齐备候选先按净年化和回撤原始值做帕累托分层；同层按参数收益Q10、参数回撤Q90、滚动超额收益Q10、费用压力年化损失、最大单笔盈利贡献、60日交易数中位数依次排序。
前五项按0.0001比例单位向下分箱，频率按0.5笔向下分箱，原点均0；方向依指南。全部相同则并列，ID仅稳定展示。
参数整组不适用的候选，前两项取各自业务方向的最低有效排序待遇，优先级低于所有有效实测值；不补造Q10/Q90数值。其他缺失证据不享受该待遇。
排序用于支持选择，不代替全部目标验收或用户选型。

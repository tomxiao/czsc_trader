# DEV 平台上下文性能验证附加材料

此包保留用户授权平台性能修复期间已经生成的独立合成验证证据。此次仅逐字节复制和核对哈希，没有重新运行策略、账户、诊断或计时；不增加研究假设，不占实验额度，不替换 EX017 已冻结的策略、协议或 pre_run 材料。正式平台应用后的聚焦测试、正式账户及报告发布由主流程另行记录。本包 PASS 仅指所列合成等价检查通过，不是阶段推进或全仓验收。

## 文件与身份

- `before_validation/`、`after_validation/`：原始结果及各三条路径的七张完整 JSON 表。
- `comparison.json`：原始比较结果；`before_session_profile.json`、`after_session_profile.json`：独立无辅助会话上下文计时。
- `source/`：验证脚本与旧、新平台模块原字节快照；扩展名增加 `.txt` 避免从证据目录误导入。`baseline_equity.py.txt` 与 `baseline_equity_definition.py.txt` 保留当时调用方源码。
- `EX017-interruption.json`：原始受控技术中止记录，未产生或发布账户结果；同固定配置将在新实现身份下技术重跑，不是新增研究轮次。
- `checkpoint_manifest.json`：原检查点身份清单。原检查点仍位于仓库根目录下 `.tmp/s017-context-performance/EX017-before-performance-checkpoint`；本包不复制私有账户绩效。中止记录中的命令、时间与原路径按原字节保留。
- `manifest.json`：本包全部材料的相对路径和 SHA256（清单自身不自哈希）。

## 验证覆盖和边界

三条受支持 US 公开 SRT/TXE 链路为：无辅助、仅会话上下文、日线加 M30 辅助及会话上下文。每条各 59 次决策、26 笔实际合成成交、13 个闭合周期；决策、订单、成交、公司行动、账户时点、账户日表及周期七张表全部逐字节相同。公司行动表在这些用例中为空，未证明非空公司行动经济账本等价。

未来 OHLCV 扰动不改变既有七表；输入 DataFrame 保持不变，公开 validate 返回的主数据和辅助数据副本可变隔离，重复决策一致。12 项错误/拒绝（11 项数据或会话异常加 CN 执行拒绝）前后类型及文本完全一致，包括非当前会话的非整柱网格异常。注入后的实际调用计数为 build 265、validate 260、auxiliary 567，证明不是绕过优化入口的空路径测试。

CN 仅验证无辅助公开 plan 和原有显式拒绝 CN bar execution 的契约。旧 A股实际主链的独立回归由主流程另行完成；不能将此拒绝检查当作 A股完整执行保全证明。候选 pickle 往返通过。本包没有验证非空公司行动、真实行情、整库回归，也没有模拟新的可交易收益。

## 时间边界与计时定义

全部输入为合成数据，无任何 2026 行情；七表回放使用 2019 数据，长日历基准从 2019-10-01 至 2025-11-17（1600 个合成工作日，不声称真实交易所节假日日历）。包含 DST 切换及合成半日会话。主历史窗口 273 柱，长辅助集日线 1600 行、M30 20794 行。

旧、新模块分别在独立单进程中加载为同名模块，并重绑公开 build 导出。顺序执行，OMP、OPENBLAS、MKL 线程均为 1。每个微基准先预热一次，然后 3 次重复、每次 6 个 operation；operation 精确定义为公开 build 一次加 validate 一次，不包含策略执行或 TXE。调用计数为 19 次 build 和 19 次 validate。

仅会话上下文：每 6 次操作中位 0.2752416 秒降至 0.0528016 秒，折合每操作 45.8736 毫秒与 8.80027 毫秒，约 5.21 倍。这里声明的辅助输入为空，实际 auxiliary 调用为 0；原计时 JSON 的 auxiliary_rows 仅记载 fixture 内存在但没有读取的辅助表大小。

日线加 M30 辅助：每 6 次操作中位 1.0852378 秒降至 0.3234314 秒，约 3.36 倍。原始每轮耗时均保留。短合成回放的单次耗时亦保留，但未做重复统计。所有墙钟时间受同时运行任务等本机环境影响，不能宣称正式账户或完整诊断全链路快 5 倍，不能仅凭微基准保证总耗时。

## 复核方式

先逐项核对 manifest，再核对原 result 中记录的模块、脚本和各表 SHA。需要复现时，在新的临时目录复制 `source/` 文件并去掉末尾 `.txt`，恢复原文件名；沿用仓库依赖及源码路径，分别执行 `compare_context.py --module before_equity_context.py --label before_validation` 与 after 对应参数，再执行 `--compare before_validation after_validation`。两个 session profile 同理执行。不要直接在此归档目录生成或覆盖证据；此次归档未执行这些复现命令。

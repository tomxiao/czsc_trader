# 冻结S015-v1观察契约升级

只增加声明式信号观察，能否保持交易与经济路径完全等价？

## 本轮授权与边界

用户批准新开分支，由 DEV 修改平台、RSCH 升级策略观察。实验仅派生 S015/C9800 观察升级候选，不重新搜索、不新增行情、不改变参数和交易代码。原 S015-v1 冻结包、研究证据、生产账户均不修改；精确冻结和生产改绑仍待单独批准。

## 准备与验证记录

- 初稿 `protocols/observation_upgrade.json` 只记录初始观察设计。正式计算前补充预热可用性声明，最终身份固定于 `protocols/observation_upgrade_final.json`；初稿没有登记成候选或发布为策略。
- 原模型预热时的填充值不能解释为真实价格或条件。观察层为未完成观察期与起始种子日声明 `UNAVAILABLE` 及原因；交易函数不变。
- 新观察 helper 只由两个观察扩展方法局部导入。原全部交易 AST、原业务定义以及原四条 series/facts 保持不变，已通过平台公开受限观察升级校验。
- 使用 EX082 已认证的真实准备数据，历史窗口为 2025-01-02 至 2026-10-21。WINDOW 与 CONTINUOUS 各 434 日、109 笔订单、108 笔成交、54 个完成交易，五账本经济事实零容差相同。
- 非零持仓探针每模式 8 个，覆盖 200/600 份、显式既有资金周期和入场/有效/退出信号日。两个模式均通过。
- 标准费率 0.1% 和每侧 0.2% 倍费场景均保存平台账户评价。通用账本比较器将新增观察列报告为 `FIELDS_DIFFER`，该原始输出保留；按本轮声明只排除新增 `obs_` 列，并对内容身份相关 ID 检查双射后，所有原经济字段逐值相同。没有放宽数值容差。
- 追加窄窗口 2026-01-05 至 2026-10-21 检查：191 日 WINDOW 的全部交易/观察值与全窗对应日期一致，机会激活标识跨窗口稳定；CONTINUOUS 全历史同样一致。
- 首轮正式技术检验期间平台完成验证边界修复，触发 `ENVIRONMENT_MISMATCH`；原失败报告和不可变证据保留。第二版只重新固定稳定平台身份，其余候选、渠道事实、检查条件和容差不变。

## 显示语义

入场条件分别展示当前价格距离中心的修复空间及其门槛、中心上移幅度及零分界，并显示完整条件是否满足。机会边界将对数价格还原成后复权参考价格，显示当前中心、激活时固定的修复目标和中心失效线。模型机会失效后隐藏固定边界；每个机会使用激活日期作为独立段标识。中心失效线用于比较中心，不是账户成交止损价；模型机会也不等同于已经成交持仓。

## 证据边界

本轮是观察升级技术复验，不新增策略收益或普适性的证据。PTE 技术检验的渠道事实是独立规定的合成事件，不代表生产实盘成交。191 日界面预览明确为历史技术回放，保留原行情、账户、事件区及原 series/facts，不冒充前瞻观察。

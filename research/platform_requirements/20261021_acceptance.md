# 阶段一目标与稳健性验收的平台需求

状态：用户于2026-10-21确认研究标准，完成DEV方案评审后授权新分支实施。本文保留需求及验收依据；实现已纳入现有SE与TDR公共入口，接口使用以模块说明为准。本次不改变历史研究资格，不批准生产变更。

研究政策以[RSCH指南](../RSCH_AGENT.md#2-用户目标与研究约束)为准。工具使用继续以[TDR使用说明](../../src/czsc_trader/README.md)为入口；实现后由DEV同步TDR及其引用的模块手册，不另建一份研究工具使用手册。

## 1. 目标与范围

将已确认的中心经济与频率、参数扰动、费用压力条件纳入同一套可复算、可留证的验收，避免平台返回部分达标或排序成功被误认为完整准入通过。

平台只计算账户事实、比较显式条件、核验身份及证据完整性。机制是否合理、数据是否足以支持独立结论、是否值得继续研究，由RSCH判断；平台不读报告语义、不推断用户批准、不发现或消除过拟合。

本轮不修改策略、历史账户、历史批次资格或已发布证据，不涉及DFLS数据获取、SRT策略公式、TXE撮合规则、SM策略状态或PTE生产运行。25%是研究验收上限，不产生运行时止损、暂停或告警行为。

## 2. 确定性验收合同

记标准场景策略、buyhold的净年化为Rs、Rb，最大回撤正幅度为Ds、Db；扰动点为Ri、Di；压力场景使用Rs*、Rb*、Ds*、Db*。所有收益扣费，使用同一完整评价窗口、资金及可比执行合同。标准场景每侧0.001成本，压力场景每侧0.002成本。

### 中心经济与频率

| 条件 | 精确规则 |
| --- | --- |
| 正基准收益 | Rb > 0时，Rs >= 1.5 × Rb |
| 非正基准收益 | Rb <= 0时，Rs > 0 |
| 相对回撤 | Ds <= 0.8 × Db |
| 绝对回撤 | Ds <= 0.25 |
| 常态频率 | 每日移动的完整60交易日窗口闭合交易数中位数 >= 6 |
| 冷清时段频率 | 若完整窗口数为N、至少3笔闭合交易的窗口数为K，则10 × K >= 9 × N，且N > 0 |

闭合交易按退出日归属，窗口前入场、窗口内退出计入；未退出不计入。N = 有效账户交易日数 - 59，不足60日为证据不足。窗口使用原连续账户，不重置本金、资金或持仓。中位数偶数样本取中间两值的均值。90%直接按计数判定，不用LINEAR Q10替代；例如10个窗口中1个为2笔、9个为3笔，覆盖率90%通过，但LINEAR Q10为2.9。

复合净年化按252交易日计算；最大回撤包括初始财富及持仓市值，从连续净值历史高点计算。先按完整精度判定，再按展示精度格式化；等号及严格不等号不得被显示舍入或额外容差改变。

### 参数扰动

事前固定全部32个有效设计点；保持中心源码、结构、窗口、费用、基准及其他非参数条件一致，沿用既有设计身份绑定及校验。默认域宽标准化5%总欧氏距离和种子13，不能解释为每个参数分别变动5%。研究员负责参数域及映射的业务合理性。

每个点的联合经济条件为：

- Rb > 0时Ri >= 1.25 × Rb，否则Ri > 0；
- Di <= 0.9 × Db。

验收要求联合经济条件至少26/32点通过，且32/32点均满足Di <= 0.25。收益与回撤须在同一点同时通过，不能分别统计后拼成联合通过。固定门槛不随中心最佳收益变化；不额外要求扰动点通过中心双频率目标。Q10收益、Q90回撤仍用于原有排序和解释，不能代替逐点验收。

缺失、技术失败、重复或不可比证据不得填零、替点或缩小分母。完整通过需要全部32点有效；部分事实可以展示，但不能生成完整通过结论。纯整数、类别或无参数策略沿用不适用/方法缺口状态，须事先另定检验合同，不自动通过。

### 费用压力

中心参数及窗口固定，策略与buyhold均在压力费用下重新计算：

- Rs* > 0且Rs* > Rb*；
- Db* > 0时Ds* < Db*；Db* = 0时Ds* = 0；
- Ds* <= 0.25。

不能引用标准场景buyhold代替压力基准；不能仅以标准与压力之间的年化损失判断是否通过。不要求压力场景保持1.5倍收益或中心频率，也不交叉执行32个扰动点的费用压力。

### 必报诊断与阶段用途

逐年、滚动252日（默认步长21日）表现、利润集中、超额收益区间及适用的选择偏差诊断继续报告，不增加统一数值硬门。重叠窗口不作为独立样本计数。年度及窗口切片继承原账户状态，边界不完整年份显式标识。连续落后的具体定义在批次协议中固定。

阶段三交接经济与频率达标候选；阶段四对全部交接候选完成规定自检，只有经济、频率及稳健性均达标且可比者进入推荐排序集合。候选选择、冻结及部署仍遵守既有用户决定流程。数值验收通过不等于独立统计证据充分，也不自动授予冻结或PTE操作权限。

## 3. 需求与实现对应

已核对[SE类型](../../packages/strategy_evaluator/src/strategy_evaluator/research_models.py)、[SE计算](../../packages/strategy_evaluator/src/strategy_evaluator/research_assessment.py)、[TDR交付类型](../../src/czsc_trader/research_tools/delivery.py)及[TDR交付服务](../../src/czsc_trader/application/delivery_service.py)。

| 能力 | 原有基础或缺口 | 实现 |
| --- | --- | --- |
| 中心净年化、回撤与倍数条件 | 已有常量、基准倍数、严格/包含边界及基准条件 | 复用`ResearchTarget`，覆盖正/零/负基准和零回撤边界；可声明实际费用 |
| 频率中位数 | 已有逐日60日闭合交易计数及中位数 | 复用 |
| 90%窗口至少3笔 | 原只有插值Q10等诊断 | `FrequencyCoverageTarget/Facts/Check`保存阈值、N/K，以整数交叉相乘验收 |
| 同时验收两项频率 | 原要求全部频率目标等于唯一排序频率 | 验收条件与单一排序频率解耦，继续校验窗口口径 |
| 参数26/32联合通过、全部点回撤上限 | 已有绑定设计及Q10/Q90 | `ParameterGroupTarget/Check`与逐点事实，保留同点联合及全部点条件 |
| 压力场景验收 | 原主要提供年化损失诊断 | `TargetScope.STRESS`与压力绩效事实，使用压力账户自己的基准 |

最新收益目标已改为倍数，本轮不需要“基准加固定百分点”新能力，也不需要通用布尔表达式或任意指标计算语言。

## 4. 公共入口与输入输出

继续使用既有自检、比较和交付入口；不新建独立的“准入服务”。精确字段和可运行构造示例见[SE验收契约](../../packages/strategy_evaluator/README.md#经济频率及稳健性验收)，正式留证见[TDR目标绑定](../../src/czsc_trader/README.md#完整目标集合的交付绑定)。

| 现有入口/合同 | 输入 | 输出 |
| --- | --- | --- |
| SE `assess_candidates(CandidateAssessmentRequest)` | 在既有中心、扰动、压力账户证据及自检协议上，增加强类型窗口覆盖定义：窗口60、最少闭合交易3；保留标准/压力及基准身份 | `AssessmentPanel`增加每中心窗口总数、达标数、覆盖率和口径；验收所需扰动点收益/回撤及证据关联；压力策略与同场景基准收益/回撤及身份 |
| SE `compare_candidates(CandidateComparisonRequest)` | `ResearchTargets`继续声明中心目标；增加强类型参数组要求和压力目标，绑定规定场景/设计。参数组声明规定32点、最少26点联合通过、逐点经济条件及全部点回撤上限。排序频率独立于双频率验收集合 | 逐条件状态、实际值、边界、原因、证据引用；参数实际覆盖、联合通过数、违反风险上限的点；完整准入状态及既有排序结果 |
| TDR `assemble_delivery` / `validate_delivery` | 阶段一目标声明及确认依据、阶段四实际协议/面板/比较结果和已有证据引用 | 留存新合同；验证条件与获批目标一致；FULL校验由相同公共计算入口复算新事实和结果。INTEGRITY校验继续仅核验其声明范围，不冒充数值重算 |

合同要求：

- 使用枚举和强类型区分中心、参数组与费用压力条件；范围/场景不能依靠自由文本推断。
- 窗口覆盖率属于比例，不能放进“每窗口闭合笔数”单位；输入最少闭合笔数、窗口长度、联合通过点数均为有约束的整数。缺失所需协议时拒绝或明确证据不足，不能默认换成其他指标。
- 参数组条件是同一点的逻辑“且”，组通过数和全部点风险条件分别输出；实现固定业务组合，不提供任意可执行表达式。
- 逐项结果沿用现有通过、未通过、证据不足/不可比语义；合法条件分支不适用只表示未触发该分支，不代表整个项目通过。未知、不适用、缺失不能被折算为通过；只有所有必需证据有效且所有适用条件成立才完整通过。
- 错误参数、矛盾场景、重复点、错误身份或非法合同应尽早拒绝；缺失账户等证据问题须在适用结果中清楚显示，不能声称检验完成。
- 排序只使用明确选定的一项频率指标，双频率验收必须全部执行。候选与其证据保留原集合；未达标候选仍可列示，但不进入通过者推荐排序。时间/集中度/PBO/DSR的高低不自动增设门槛。
- 不另建账户、账本或验收数据库。原始账户仍在TDR批次证据空间；派生结果随现有阶段交付留存。公共输出只含目标判定和追溯所需字段，不复制完整账本。

工具使用与账户位置见[TDR](../../src/czsc_trader/README.md#5-显式发布和读取证据)。必须显式传入完整获批条件；不能创建一份省略新条件却声称全部达标的正式交付。`acceptance_status`只汇总声明目标，技术交付校验成功不等于研究验收通过。

## 5. 版本、兼容与验收

当前自检为`research-assessment-v5`，排序为`research-ranking-v3`，交付定义/回执/信封为schema 8；账户证据仍为schema 7、请求身份schema 6、StrategyVersion schema 5。旧交付和旧公式明确拒绝，不实现双版本读取，不自动迁移、覆写或重算历史材料。已有当前格式账户可在新交付中显式引用；新政策由新研究约定或获批的约定修订启用。

最小验收覆盖：

1. Rb为正、零、负；1.5倍和1.25倍边界；严格盈利零值不通过；Db为零及25%恰好通过/略超不通过。
2. 59日无完整窗口、60日单窗口、跨窗口入场/退出归属及偶数中位数；恰好90%通过，少一个窗口不通过；插值Q10与覆盖率不同的反例。
3. 中位数条件通过但覆盖率失败、反之亦然；两项验收独立于所选排序频率。
4. 联合25/32失败、26/32通过；收益和回撤分别通过26点但交集不足26时失败；即使联合通过26点，只要任一点回撤超过25%仍失败。
5. 少一个点、重复点、错误设计/费用/窗口/源码绑定不得完整通过；全部点有效后才能给出完整组验收。
6. 压力策略盈利但落后压力基准、压力回撤等于正回撤基准、零回撤基准分支、错误复用标准基准，以及只提供年化损失的不足证据。
7. 阶段一条件与阶段四条件不一致、缺少确认依据、伪造派生结果由FULL校验拒绝；INTEGRITY与FULL不混淆。相同输入复算一致。
8. 未达标和证据不足不进入通过者推荐排序；旧协议和历史证据不被改写。更新TDR使用说明、SE合同说明及相关示例，清楚标记新的支持范围。

数值和强类型边界由[SE验收测试](../../packages/strategy_evaluator/tests/functional/test_research_acceptance.py)承接；目标绑定、持久化及伪造结果拒绝由[TDR交付测试](../../tests/functional/test_assessment_delivery.py)承接。回归覆盖SE、交付存储/依赖链/概览及合成冻结流程。合成软件测试不代表真实策略已达到新标准，也不改变既有冻结或PTE状态。

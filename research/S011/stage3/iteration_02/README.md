## 3. 表达与固定身份

定义R为历史窗口内的中心化经验秩，含当前已完成日，采用并列值中位秩。tail_score=-R(ETF尾盘90分钟收益)，market_score=-R(沪深300日收益)，spx_score=R(严格较早可得的SPX日收益)。

```text
score = (0.575*tail_score + 0.425*market_score + 0.05*spx_score) / 1.05
lookback = 130
空仓且score >= 0.325：形成全仓买入意图
持仓意图且score <= exit，或意图年龄达到2日：形成清仓意图
买入限价 = floor(前收盘价 * 1.003 / 0.001) * 0.001
高收益方向exit=0.025；低回撤方向exit=0.175
```

T日完整信息只能驱动后续可执行订单。意图年龄从信号起算，实际成交与未成交均由相同SRT/TXE处理；没有根据未来成交或利润选择订单。COMP01/02/04参与信号，COMP03仅为诊断。entry=0.330在当前已见数据上分别复现两种相同账户，这是参数冗余，不能当成额外独立支持。

[前沿固定配置](frontier_configurations.json)包含完整payload、源码路径、实现hash、候选ID、数据/请求/结果身份。所有新实验实现字节相同，implementation SHA256为`53faf44a861c97e83ce72c7827685791530a96b1e53ee0a6cefb5dab11fab71e`。这是研究前沿身份，不创建阶段五候选包、正式冻结版本或生产账户。

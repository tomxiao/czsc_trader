- 固定2天联合扰动在20bp成本下均0/16达标，低回撤组中心在20bp下也未达原收益目标。

- 原PBO/DSR与重抽样未重算，不能宣称覆盖EX28追加评价；全部为已见开发池。
- 单尺度局部设计，高阶交互、容量、冲击、延迟及独立前瞻验证仍未充分覆盖。

本建议强调收益型研究目标和联合敏感性，同时保留回撤与单参数上的反向证据；不代表统计显著优势或用户确认的新权重。

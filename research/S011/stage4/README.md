## 2. 为什么可以有限交接

EX26接收全部26个阶段三合格参数、18种合格账户及559点完整参数目录，先检查既有覆盖。最佳配置也仅有2/7维的双侧近邻，不能据此宣称稳定区域。EX25T014在此前局部联合邻点中有6/7合格，且39笔交易比两种40笔前沿多留1笔余量，故在EX27读取新结果前登记其为固定检查中心，没有根据EX27结果重新挑选赢家。

EX27采用Optuna原生GridSampler、InMemoryStorage，固定中心加七维正负扰动，共15个参数点。每次只改变一维，结果如下：

| --- | --- | --- |
| tail_weight | 0.55：45.7104% / 是 | 0.60：43.6534% / 是 |
| spx_weight | 0.025：40.3480% / 是 | 0.075：41.1958% / 是 |
| entry | 0.320：47.3887% / 是 | 0.330：47.0479% / 是 |
| exit | 0：45.3742% / 是 | 0.050：43.8185% / 是 |
| max_days | 1：36.1976% / 否 | 3：43.0004% / 是 |

14个邻点13个达标，六个维度双侧均达标；持有期缩至1日不满足收益门。15点对应14种经济账户，entry=0.330与中心交易行为相同，不计作新增独立支持。中心年化高于原40.1648%收益门约6.8831个百分点；spx_weight下侧仅余0.1832个百分点，参数区域并非处处宽裕。

**研究判断：当前证据支持局部代表的交接价值。**多数单维扰动保持达标，中心无需精确卡在某一个阈值，且成本加倍后仍勉强达原门槛；较短持有期失败也限定了该短周期反转表达的适用范围。13/14不是预设通用晋级门槛或成功概率，不要求所有诊断机械通过。保留全部合格配置及原两种前沿，不把被选代表称为收益—回撤最优。

**联合覆盖限制：**这里未建立七维联合立方体、完整交互模型或独立稳健平台。阶段三的entry/exit/premium联合检查和EX26的既有联合邻点只覆盖部分相互影响。单轴合格不能推出同时改变多个参数仍合格；下一阶段只能交接固定版本，并把该缺口交给CIO审阅。后续变更参数须重新研究，不能沿用此次代表资格。

## 3. 成本、成交与时段风险

EX26用26个合格参数及固定EX16整手基准，各跑8档成本，共216条完整SRT/TXE账户；EX27的15点再跑8档，共120条。费用直接进入下单数量、现金、成交及权益；基准也按相同费用重算。未使用平台自动生成的非整手基准，未以回测收益事后扣费替代重放。

20bp时基准年化26.6958%，对应收益门40.0437%；各档按同成本比较，标准成本合同仍为10bp。成本档位是离散诊断，不能推断精确盈亏平衡点。代表在三种报价扰动下保持39/39/40笔达标，支持有限报价余量；成交仍采用历史开盘/严格触价模型，未验证真实盘口排队、成交容量、冲击和延迟。加费用无法模拟漏单、错过触价或时间延迟。原始未成交也保留：中心有6张未成交订单。

- **分段差异：**代表2025部分区间收益37.3628%，低于基准39.2964%；2026截至截止日收益34.8752%，基准4.9157%。2025Q3只获3.9121%，基准25.6686%；2026Q3亏4.4151%，基准亏25.4898%。收益来源包含避免大跌与漏掉强涨的取舍，无法承诺各期领先。
- **滚动与集中：**344个重叠60日窗口中约60.1744%跑赢基准，最差落后26.9121个百分点。39笔闭合交易中28笔盈利，前三笔占正利润33.9037%。将最佳3天账户收益机械置零，年化降至29.8081%，低于原门槛；这是集中度反事实诊断，不能当成可执行的新策略。
- **不确定性：**10/20日循环区块、各2000次成对重抽样，年化对数超额的2.5%—97.5%范围分别为[-0.2686,0.6102]、[-0.2612,0.6116]，均跨零；正值重抽样比例74.95%/74.80%。这些值不是未来获利概率、不是CAGR差值，也未校正完整搜索选择偏差。不能用它们宣称显著或独立Alpha。
- **开发池边界：**全部行情及此前S010/S011选择历史均已见，没有独立样本或前瞻证明。当前两段年度结果、重叠滚动窗口和重复参数不增加独立证据数量。

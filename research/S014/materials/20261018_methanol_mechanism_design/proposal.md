# S014 甲醇信息增量机制方案

日期：2026-10-18。身份：RSCH。性质：方案评审，等待实验授权。本轮未计算甲醇变化与股票收益的关系，未运行模型或账户，未新增数据调用。

**建议下一步回到阶段二，开展一项固定方向的信息增量检验：甲醇前一完整交易日上涨，是否在既有股票、市场和行业信息之外，提高金牛化工“低开收阳”机会随后三日的可执行净收益。** 主问题只保留这一项；共同行情、股价已经反映、换月假象和少数大行情作为竞争解释，不把它们拆成多项可任选的Alpha。

## 1. 为什么研究，以及与旧实验的区别

甲醇商品价格可能包含股票日线尚未充分反映的信息，这是待验证假设。期货上涨不等于公司利润必然上涨，也不预设股价应该上涨。这里的“一日变化”是可观测价格代理，不能解释为已识别的外生供需冲击。

## 2. 锁定输入、时点与样本

正式准备引用来自[补齐验收](../20261018_methanol_completion/acceptance.json)：`4146c628-74a5-4404-ae3d-cb47cd2c124b`，清单哈希`c3e805362169a33be8756ae7606c1f60f5b392495772fe9877c679d9ce993c8f`。复用22个原合约、映射、日历及既有股票/指数资产；不刷新来源。

- T为股票收盘决策日，P为严格早于T的最近CZCE开市日，Q为P之前的CZCE开市日，K=M(P)。仅当映射及两条行情AvailableDate不晚于T的15:00且原价有效时，定义`r(T)=Close(K,P)/Close(K,Q)-1`。两个价格始终同一K。
- 唯一新增主特征`z(T)=1[r(T)>0]`；非上涨包括0，另列精确零样本数量，不把缺失记为0。不扫描百分比、分位、幅度、期限或方向，不把负结果自动改写为反转策略。
- 父机会A固定为股票HFQ的`Open(T)<Close(T-1)`且`Close(T)>Open(T)`。未来验证须复现旧父条件；不按后来盈亏、历史账户是否实际买入或是否属于高环境挑样本。
- 甲醇在2020-01-06至2026-10-15共1640个决策日具备两日端点；这不是1640次父机会或已成熟标签。2020-01-02、01-03信息未就绪；更长特征预热、标签成熟及H3环境启动另列，不混为上游缺数。
- AvailableDate是用户接受的使用约定；历史首次发布及修订版本仍未证明。全期股票结果已经用于研究，新的商品变量也不能把这一时期变成独立未见样本。
- 换月M(P)≠M(Q)只作事先标记，主分析保留。日历错位、停复牌依原规范，不按自然日减一，不取T日或之后夜盘的完整期货数据。

## 3. 最小对照设计（全部待执行）

### 固定标签和共同队列

主标签为旧H3：买入后的第3个交易日计划退出，实际卖出遵循原执行约束；H1为固定期限反证，不按结果替换主期限。二者同一入场、股数和费用，以净现金变化除以初始10万元。必须核验已有标签的来源、成熟日期、SRT/TXE执行身份及价格/股数；身份不一致则停止相关比较，报告修复范围，不静默重跑或拼接。

未成交尝试记0收益并单列数量；截至窗口末未成熟的持仓单列，不能填0、强平或只报告成功退出。H1/H3差异只在共同成熟的同一组尝试上比较，同时分别披露各期限自己的完整成熟队列，防止截断选择被掩盖。所有尝试可以重叠，仅为组件标签，不构成可投资账户。

描述性全期表覆盖所有具备父条件、甲醇信息及标签的日期，2020—2022明确单列；条件增量评价固定沿用2023—2026年度时间外推，之前数据用于训练。基线和新增信息必须在完全相同的训练/评价行上比较，不能直接拿旧报告均值相减。

### 强基线和新增信息

基线B固定为EX010当前`both`信息块（股票19、市场7、原相对响应4、行业7、双因素/行业独立变化7，共44项），加其股票滞后反证采用的前一股票日股票7、市场7、行业7，共65项；按既有定义并集，名称重合不得重复计入。前一股票日与P是否一致须按日历核对，不能偷偷用股票行位移替代期货P。既有60日系数只用T-1及更早数据。

65项确切列名锁定在[设计清单](design.json)。定义复用EX010的`sector_features.py`、`followup.py`与`stock_lag.py::augmented`：当前股票收益保留原定义，`prior_stock_ret1/5/20`沿用先log1p再shift，市场前一期列为`prior_`、行业为`lag_`；不凭中文块名重写。源码哈希见[来源清单](source_manifest.json)。

固定使用既有标准化及Ridge(alpha=10)，不做树模型、超参数优化或新增特征普查。每年只使用实际退出成熟日期严格早于该年首个评价信号的训练标签；标准化和筛选阈值均仅从该训练集取得。训练沿用全有效信号队列，评价聚焦A，避免因新组别稀少更换训练母体。B本身也在相同队列重拟合，不冒称这是已发表的65项基线结果。

年首截点固定取三模型共同可用的全信号队列首日，不取A子集首日；训练q75也取全训练行的拟合分数，不取A或甲醇上涨子集。共同可用性同时要求B、z、z_old5有效；H3成熟后才进入评价，实际起止日和排除原因逐项记录。

| 对照 | 固定做法 | 回答的问题 |
| --- | --- | --- |
| 全父机会 | A内全部尝试，固定H3 | 保留原机会规模、均值和损失组成 |
| 商品方向直接分组 | A内z=1对z=0，报告原始差；再比较`Y_H3−B预测`的组间差D1 | 股价与指数已有信息以外，商品方向是否仍能区分净收益 |
| B与B+z | 仅增加z；均使用各自历史训练预测分数的75%分位筛选，沿用旧实现的大于或等于边界，报告并列与实际选择率 | 新信息加入同一方法后，是否改善每个父机会的净分配D2 |
| 原H3环境分层 | 复用EX016的年度校准版本，分别列高、低、未就绪 | 商品差异是否仅是旧环境标签的替代；不按结果建立年份或环境开关 |

定义D2=`mean_A(1[selected_B+z]×Y_H3 − 1[selected_B]×Y_H3)`。未选中记0，未成交仍0；分母是双方共同可评价的全部父机会，不只算各自选中交易的均值。列出双方共同选中、新增、被移除、共同不选四组及净贡献；同时展示B+z与全父机会的净分配差，不只挑容易超越的基线。

D1=`mean(Y_H3−B预测 | A,z=1)−mean(Y_H3−B预测 | A,z=0)`。D1、D2均只在2023—2026时间外推的共同父机会队列上作为主比较，预期均为正；2020—2022的全期原始分组只作描述，不能混入主预测增量。D1只能表示对这一基线的条件关联，不能宣称已排除所有共同因素或证明甲醇因果推动股票。D2改善而D1反向，也不自动算主机制获得支持，应报告定义与证据不符。

H1只用相同H3分数及选择掩码读取已存在的H1标签，不重新训练H1模型、不选最佳退出日。H1与H3分别比较后，报告同入场的H3−H1净变化：解释效应是否延续到拟研究期限，不宣称更长持有一定更优。

### 反证和依赖诊断

1. 分年、去2026、逐个年份剔除，披露样本数量、方向与贡献；不得见到反例后加入年度启停。
2. 主分析保留换月；补充去换月日结果。若差异只发生在换月或某个合约，不宣布一般商品传递机制成立。
3. 时间安慰剂固定为`z_old(T)=z(T之前第5个股票交易日)`，每个旧z使用其自身已核验的K/P/Q，不能在当前K上向前索取未授权历史。B+z_old采用同一年度拟合；三个模型在共同可用队列比较。它检验近期方向是否具有额外信息；旧方向也有效不能单独否定缓慢传递，只能削弱“近期冲击”解释。不得使用未来z或置换后声称真实交易结果。
4. 事后实际持有区间重叠簇等权、删任一簇、固定时间顺序的区间去重，以及每年去掉最有利的3个贡献，显示结果是否被少数行情控制。这些是依赖诊断，使用实际退出的去重结果不是事前可交易排程，不据此认定交易频率达标。
5. D1/D2使用同一整段交易日历、按年20交易日区块重采样2000次，60日块作固定敏感性；保留非事件日以及标签、事件、模型选择的对应关系，每次重新计数组别和分母，缺组抽样记失效，不强制保持原组数。报告普通95%与两主比较同时区间；在固定已拟合分数下计算，不包含重新训练的不确定性，也未消除既有多轮选择偏差。H1、分层、去极值均为诊断，不从中挑显著结果替代主比较。

## 4. 验收与后续决定

### 技术验收

数据与标签身份、共同样本、同合约时点、训练成熟边界、费用股数、未成交/截断记录必须正确并可独立复核。任何失败先记为技术不可评价，不能当作收益机制无效或有效。本次方案确认不等于这些计算已执行或通过。

### 研究用途判断

| 结果 | 允许的结论与行动 |
| --- | --- |
| 主H3方向与净分配均支持预期，加入强对照后仍有实际增量，主要反证未给出更有力的替代解释，机会覆盖及不确定性可解释 | 可提出“商品方向条件组件”的有限用途及适用范围，交用户评审是否值得进入连续账户对照；仍不称稳定Alpha或年度达标 |
| 原始分组好，但D1或D2明显削弱，主要由旧股票状态、单年、少数行情或换月解释 | 不确认新增收益组件；明确是哪个竞争解释得到了支持，关闭当前固定定义或提出新的可区分问题，不继续扫阈值 |
| 平均净收益无改善，但负收益贡献较小且伴随正收益损失 | 只能报告风险与机会代价线索；不能把主收益假设失败改名为成功，也不能直接当作有效风控组件 |
| 组别/年份覆盖不足、区间很宽或关键反证互相冲突 | 记为证据不足，列明需要什么证据；不因样本内均值为正、统计区间不跨0或实验完成就收口，不自动扩源 |

以上用于判断组件是否值得继续，是待确认的研究证据标准；不新增账户经济硬门，不要求组件每年同号，也不把固定样本数或p值变成自动否决条件。若总体正向但不确定性仍足以改变决策，应留在证据不足，而非直接登记有效入场组件。数据覆盖与预测增量分别验收。

完整策略的原目标逐项保留：研究2020-01-01至2026-10-15；每个自然年BuyHold收益为正时策略至少其1.5倍，否则策略严格正收益；每年策略最大回撤幅度严格小于BuyHold；2026截至10月15日纳入且不年化；`60×全期闭合交易数/1642≥3`。组件分组统计与重叠尝试均不能代替这些条件。

资金10万元、每侧0.1%、HFQ研究与原价执行、100股单位、全仓只做多、固定前收+1%限价买入及更有利开盘成交、触价全额成交、开盘卖出/跌停开盘加一价位规则、跨年连续、无年度重置和期末强平、固定BuyHold均不变。

# S014：包含后续交易的动作价值方法评审

身份：RSCH。当前用户批准继续上一轮提出的方法评审。费用、执行约定、年度目标及既有研究范围不变。本轮只核查已有材料、接口与样本可得性，不生成新收益标签，不运行模型或账户，不请求上游数据。

**评审结论：继续S014的方法研究有具体可执行的下一步。建议先做一次固定E+6终点的三种资金结果对照，检查原来的单笔退出标签是否遗漏后续交易价值。现有证据足以支持这次低成本测量检验，但尚未建立新收益机制。** 不再把当前固定规则未获支持直接升级为整个S014必须暂停；EX033及其他已经关闭的具体规则结论仍保留。

## 1. 本次研究决定与已有事实

本轮评审发现两个会改变原建议实施方式的问题：

1. C0056提前卖出后仍保留原E+10重新入场时钟。若在原期限内比较，它多数时候无法利用提前卖出后的新机会；换成“账户动作价值”的名称，仍可能退化为EX023/EX033的旧持仓差。不能以新方法之名绕过EX029对预约与不预约的反证。
2. 原H3策略C0011更适合作为方法承载。EX019已出现单笔延长改善、完整账户反而更差的事实，原数据又能支持一个无需新账户的共同终点比较。

EX019中，浮盈延长账户与原H3共同入场的资金周期log差为+0.519230，遗漏原44笔入场的分解项为-0.961015，新增入场分解项为-0.082636。这是实际账户路径的算术分解，不能把44笔交易的全部收益都解释成延长造成的损失：两个方案都交易同一只股票，延长旧仓也可能享受那段上涨。本方法用同一初始状态、同一截止日期的资金总值直接比较，避免重复计算这部分股价变化。

原H3/H6单笔标签、P/D四种条件延长的账户、原信号续持、不同期限以及重新入场预约都已研究过。因此，本轮新增问题准确限定为：**原单笔出口差，对固定后续交易政策下的局部账户财富差，是否存在会影响动作判断的遗漏？** 本轮不重新推销浮盈、阳线或期限开关，也不声称首次考虑资金占用。

证据：[EX019](../../experiments/EX019_20261017/protocols/account_report.md)、[EX023](../../experiments/EX023_20261018/protocols/account_report.md)、[EX028](../../experiments/EX028_20261018/protocols/account_report.md)、[EX029](../../experiments/EX029_20261018/protocols/account_report.md)、[EX033](../../experiments/EX033_20261018/others/report.md)。

## 2. 三种资金结果，统一起点和终点

从C0011原147次真实入场逐项清点，使用实际买入日E后的E+2收盘作为决策D，E+6收盘作为共同终点T。D与T必须在原研究范围内可观察；不能根据未来是否顺利卖出筛选样本，不补零。已核验146个节点的D与E+6及三种终值所需字段齐备；2026-10-14最后一次入场尚无E+2，明确排除并保留库存。按决策年2020—2026依次为4、29、22、15、21、32、23个节点。具体日期与公共证据身份见[清点结果](inventory.json)。

原H3仅2026-07-23入场这一笔有卖出延期：计划07-28，实际07-29，仍早于本次终点07-31。既有146笔H6均在原计划日成交。因此本库存的H/C在E+6均可使用已保存的成交净额；未成交时按终点估值仍须作为合成边界核验。不能将这一库存事实推广到其他股票或未来行情。

E+6沿用原H3与H6比较的期限，在计算新结果前固定；不扫描哪个终点更好。所有方案都从D时实际现金、股数、已付费用与策略状态出发，分母统一为D收盘真实账户净值W_D，不能把其中一支重置为10万元。

| 标记 | 决策及后续政策 | E+6终值的计算来源 |
| --- | --- | --- |
| X：原策略 | 按原E+3计划卖出，之后继续C0011原入场及H3退出规则 | 直接读取认证原账户当日净值，已经包含后续买卖、费用、未平仓市值 |
| H：只延长这一仓 | 将这一笔改为原E+6计划卖出，不再次延长 | 截至T已卖出，用旧EX019同股数实际卖出净额加原未投资现金；否则按T收盘价估值原股数 |
| C：卖出后持现金 | 与X相同地执行原E+3卖出，之后不再买入至T | 原首次卖出成功后的总现金；若截至T仍未卖出，则仍按原股数及T收盘估值 |

主动作标签与归因项固定为：

`A = (H_T - X_T) / W_D`

`L = (H_T - C_T) / W_D`

`O = (X_T - C_T) / W_D`

逐节点核验 `A = L - O`。A衡量延长相对原账户安排的净差；L衡量继续持原仓相对卖出后持现金的差；O衡量原策略退出后继续交易相对现金的差。三者为局部终值差，不是年度收益，也不能跨节点累加成可交易账户净值。

同一股票、相同全仓约定下，三支之间的差异主要体现持仓/现金暴露、重新买入时点、费用和交易时钟。X中新交易赚到的收益已经进入X_T，不再额外加一次所谓“错失交易收益”。买入费用在D前已支付，不重复扣除；终点持仓不假设清仓，不虚构卖费。

## 3. 一期可以不用新账户回放

EX019已公开保存原股数、入场实际支出、H3/H6计划与实际卖出日期，以及已计算的卖出成交价格；C0011认证账本保存每天现金、股数、收盘估值与净值。E+6之前H只有原仓，故上述终值可以由旧成交结果和旧账本进行精确算术构造，不需要调用新的撮合函数，也不用新写一套账户执行器。

必须核验旧H6标签与原C0011的入场日期、cycle_id、数量、价格尺度和费用身份完全相同。优先使用已保存的实际成交价与数量，原收益比率只用于核对。若卖出延期到T之后，禁止使用之后的实际卖价代替T估值；T收盘价来自同一认证原账户行情尺度，即使原账户此时持有别的周期也不会改变该日市场价格。

这仍然是**新增局部反事实收益标签**，不是“完全复用旧结果”。X是原完整账户；H与C是到固定终点的局部资金估值，不包装成两条新的连续账户。

本轮已核查公共TDR也能在后续通过研究策略的一次性干预完整回放来验证更远终点，不需要新增平台快照接口。但当前没有必要先申请上百次新账户：一期先回答E+6内的测量差异是否值得继续研究。未实现或执行这些后续分支。

## 4. 固定报告与反证

拟议一期只做测量与归因，不拟合信号，也不选择“最佳规则”。

- **全库存及技术核对：** 原147入场逐项留存，按D/T可得性确定纳入；各年、跨年和末尾截断分别报告。复现原H3/H6同股数净额，核对D现金、持仓、费用及统一尺度，逐项核验A=L-O。
- **统一口径的旧新比较：** 将原单笔出口差换算成同一W_D分母，再比较原动作偏好与A的同号、异号、零值和幅度。分开报告后续交易项O、卖出延期、固定终点估值和分母变化，避免把口径差异误称为新信息。
- **后续参与覆盖：** 列出原卖出后至T实际未再入场、已经再入场及T仍持仓的节点，保留盈利和亏损，不能只挑后续大涨案例；未来再入场事实只参与标签诊断，不进入D信号。
- **全年度与集中性：** 主分组按D年份，同时保留E年份。去2026检查要求D及T均不晚于2025-12-31，不只按入场年份筛选。报告区间[D,T]的传递重叠簇、逐年、按簇等权及逐次删除一个簇的结果。固定按后续交易项绝对值|O|降序删除1/3/5个节点，等值按D及cycle_id升序，重新汇总A/L/O与同异号比例；不会将少数成功节点当独立重复证据。
- **终点剩余状态：** 三支是否现金、仍持仓或待卖、原计划退出日期均展示。E+6只是局部比较期限，两支在期限外的风险和机会可能不同。

数值零只按预先声明的浮点误差容忍处理，不用于优化动作阈值。各诊断描述证据及局限，不增加原经济硬门，也不将一次统计区间作为组件通过条件。本轮不训练P/D开关、不做零阈值邻域、期限搜索或强化学习。

## 5. 什么结果能推进研究

1. **差异很少或主要来自个别行情/成交延迟：** 旧单笔标签对本窗口动作价值的遗漏不足以支持将研究重点放在换标签上。关闭这个方法解释，保留负面证据，不继续调终点挽救结果。
2. **差异广泛且具有经济幅度，后续参与项确实改变动作排序：** 说明需要把后续参与价值纳入后续信号研究。它只支持测量方法有必要，不证明D时能够预测这些差异。
3. **尺度、状态或成交身份无法对齐：** 作为技术不可比较报告，不填值、不使用私有回放兜底。

第二类结果出现后，也不能直接拟合或形成账户候选。应先评审固定E+9终点的延伸是否值得，以核验结论对截止日期的敏感性；这需要延长支卖出后恢复原策略的新路径，应通过公共TDR并另获账户额度。E+9不能用现有H6单笔标签硬拼，也不能根据E+6结果改成有利期限。更远终点、模型、连续账户及新增数据目前均不在执行范围。

方法有用之后仍须提出具体的、在D已知且区别于已做P/D及原信号续持的信息假设。不能使用未来再入场是否赚钱、未来真正退出日或事后最佳动作作信号。该方法主要处理持仓与后续参与，不能撤销D之前已发生的入场损失，不能承诺修复三个失败年份。

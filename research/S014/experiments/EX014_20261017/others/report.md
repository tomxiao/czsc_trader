# S014 固定H3环境：下行损失与修复持续时间

**本轮补强1项已有组件的用途证据：信号日属于既定低环境时，同一入场从H1延长到H3存在平均收益侵蚀，可作为延长持有的风险参考。没有新增组件定义，没有证实新的入场筛选器或最优退出规则。** 组件总定义仍26项，获支持职责仍为原2项辅助加1项环境参考；阶段二保持PARTIAL。

四项事前风险假设未形成新的充分支持组件。“市场与行业同时走弱”在原样本有较重损失，但相近价格条件匹配后的差异依赖单个行情片段，严格去重后反号。公告继续暂停，新增上游调用0；单边0.1%费用及全部既有执行约定保持。

## 1. 固定的比较对象

沿用EX013的20日开盘缺口自相关、四个年度已成熟训练阈值和低开收阳父条件。高/低是相对年度阈值，不是自相关正/负。所有期限都使用同一个信号日H3环境分类，未按结果重新选择窗口。

输入仅为原2020-01-01至2026-10-15股票、市场与行业数据和已发布的实际执行标签；评价2023—2026部分年度，全开发池已见，不是独立封存验证。10万元、T+1限价入场、Hn在入场后n个交易日计划退出，实际延迟按原约束。净收益为真实股数净现金除初始资金；未成交0，右截断排除。

H3损失主面板保留216次父机会，其中高156、低60。五期限共同成熟面板为211次（高151、低60），剔除5次均为2026高环境。期限比较验证同一信号的入场日、数量和买价一致。H1不是信号次日卖出，也没有改成日内回转。

设计及后续顺序：[主设计](../../../experiments/EX014_20261017/protocols/design.json)、[定向反证](../../../experiments/EX014_20261017/protocols/followup_design.json)、[低环境延长持有反证](../../../experiments/EX014_20261017/protocols/duration_falsification.json)。后两项见前段结果后提出，明确属于适应性研究。

## 2. 原H3环境主要增加盈利贡献，并非全面避损

下表把每次净收益拆为正部与负部，未只在亏损子样本中计算损失贡献。

| H3环境 | 次数 | 平均净收益 | 正收益贡献 | 负收益贡献 | 亏损频率 | 最差10%均值 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 高 | 156 | +1.6048% | +3.4984% | −1.8936% | 48.08% | −10.4584% |
| 低 | 60 | −1.1709% | +0.8834% | −2.0543% | 63.33% | −8.1488% |

高低差+2.7757个百分点中约94.21%来自正收益贡献。高环境亏损次数比例更低，但最差一成交易更差，不能把该组件升级为全面尾部保护。2025高环境仍亏，其负收益贡献也比低环境更负。详情见[收益分解](../../../experiments/EX014_20261017/others/decomposition.csv)。没有将旧adverse字段误称为盘中最大不利波动或净账户回撤。

## 3. 四项风险方向及反证

固定检验：20日下行波动占比、当天修复未完成、20日下跌日成交量占比、市场与化工行业过去5日同时下跌。连续占比分界只使用年初已成熟H3高环境训练样本中位数；3%损失线仅是诊断，未加入止损或新验收条件。

前三项没有支持原先“更危险”的方向。不完整修复原总收益差甚至+6.1281个百分点，但去2026后反向；没有因看到反号就将其重新命名为有效收益机制。

共同走弱的51次相对其余105次，原负收益贡献差−1.5468个百分点，亏损超过3%的比例33.33%对15.24%。但有效控制改变了判断：

| 对照 | 共同走弱−其余的负收益贡献差 |
| --- | ---: |
| 原样本 | −1.5468个百分点 |
| 同年度波动四分组共同覆盖加权 | −1.0932个百分点 |
| 控制股票状态及市场/行业连续回报的岭模型残差 | 约−1.4148个百分点 |
| 相近价格状态无放回匹配43对 | −0.5562个百分点 |
| 匹配31个高风险腿行情簇等权 | +0.1443个百分点 |
| 匹配剔除最有利于风险假设的三对 | +0.1988个百分点 |
| 双腿及跨对实际标签区间均不重叠23对 | +0.5360个百分点 |

最强三对是同一2025行情片段。2026匹配下行差为+1.7413个百分点，方向与2023—2025不同。3/10日邻域、H1/H5、市场单跌等原对照仍有负差，却不能推翻匹配集中反证。因此保留风险线索及限制，**不新登记共同走弱风险组件**。[完整对照](../../../experiments/EX014_20261017/others/risk_neighbors.csv)、[匹配及去重](../../../experiments/EX014_20261017/others/risk_matching.csv)。

## 4. 收益持续时间：没有得到最优持有期

同一211次机会、同一入场、同一H3状态：

| 计划持有期限 | 高环境平均净收益 | 低环境平均净收益 |
| --- | ---: | ---: |
| H1 | +0.5844% | +0.0947% |
| H3 | +1.6833% | −1.1709% |
| H5 | +2.1261% | −1.6986% |
| H10 | +4.3134% | −1.9070% |
| H20 | +8.4458% | −4.5926% |

累计均值上升不能直接证明延长持有有效。高环境H3→H5全期增加0.4428个百分点，但2023/2024/2025分别为−0.4713/−0.7750/−0.2181，正值由2026带动。高环境各相邻期限增量的60交易日块普通区间均跨0。H20控制强基线后的高低残差差在去2026时反号，价格匹配去2026的H10/H20高低差也反号。更长持有还扩大了损失暴露；不能选择平均最高的H20作为退出建议。

主区间曾用20日块；后续改用60日块作长持有敏感性，非事件日也保留在交易日历内。严格去重覆盖最晚实际H20退出，保留38次，未以H3去重声称H20独立。结果见[期限水平](../../../experiments/EX014_20261017/others/duration.csv)、[配对增量更正表](../../../experiments/EX014_20261017/others/duration_increment_ci_corrected.csv)、[价格匹配](../../../experiments/EX014_20261017/others/duration_matching.csv)。

## 5. 可补强原组件的限定用途

低环境的60次入场全部成交，没有H3退出延迟。**从H1延长到H3，全期平均减少净现金/初始资金1.2656个百分点。** 去2026仍减少1.4680个百分点；60交易日块普通95%区间约[−1.9156,−0.5647]个百分点。

| 反证 | H1→H3净收益变化 |
| --- | ---: |
| 原60次 | −1.2656个百分点 |
| 39个重叠行情簇等权 | −1.1237个百分点 |
| 删除任意一簇 | −1.4630至−0.7904个百分点 |
| 实际H3区间严格去重43次 | −1.2818个百分点 |
| 剔除最负三次后57次 | −0.7098个百分点 |
| 原EX013价格匹配中的54个低环境腿 | −1.1963个百分点 |
| 原强基线H3−H1预测差控制后 | −0.8597个百分点 |

明确反例：2023原差+0.6453个百分点；2026原价格匹配低组约+0.0348个百分点。与非修复低环境匹配55对后，修复样本延长差额外−0.5849个百分点，但额外差主要来自2025，不能认定是修复独有的因果效应。

因此判断为：**支持原组件增加“信号日固定低状态下，H1延长H3存在历史平均收益侵蚀”的风险参考证据。** 这是同一组件的期限含义补充，不是新的独立信息源。没有支持H1买入必赚、H1重新计算状态后动态退出、逐年成立、最优止盈止损或完整账户回撤改善。

本线索是在多个期限/状态诊断后突出跟进，普通区间没有校正整个研究历史与全部适应性选择；支持来自多种反证汇合，不是单一区间过线。没有把每年盈利或每年同号新增为组件硬门。[逐项结果](../../../experiments/EX014_20261017/others/duration_check.json)。

## 6. 校验、交付与下一步

独立只读审查复算了收益贡献、匹配集中、低环境39簇及更正表全部70行。程序68项检查通过，覆盖已发布身份/源码、公共输入绑定、两侧费用净现金、相同入场、因果前缀、成熟训练、同队列、匹配、原组件分类及4次年度模型独立复算。[审核](../../../experiments/EX014_20261017/others/audit.json)。这些检查确认研究计算与证据，不代表账户目标达标。

保留两个技术说明：主study中注释提及配对期限区间，实际首轮只计算高低水平差，后续followup补全了组内配对区间；followup原表high布尔字段被同名区间上界覆盖，数值结果未变，新增corrected表明确state/ci_high，原件保留。研究沟通中曾把低环境四年均说成负，年度复算确认2023为正，本报告与正式判断以此反例为准。

正式交付COMPONENTS/11继承全部历史证据，维持26项定义；原环境定义与既有两项测试保留，增加期限风险参考测试及相应适用边界。没有新增有效入场组件，也未扩大为完整交易规则。阶段二未完成，阶段三未推荐、未批准。原生数据及运行资产不在Git内，须与引用共同保存。

本轮两项问题已有可复核答案，不因一个风险假设失败转向购买公告。下一优先问题是：低环境H1→H3的损失主要出现在哪个隔夜/盘中阶段，哪些入场前状态能预先区分；只有能够提出与既有价格表达不同、并可被对照推翻的机制，才继续新增验证。费用和执行约定不变，公告继续暂停。

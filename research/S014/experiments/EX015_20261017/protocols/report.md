# S014 自主阶段二第1轮：首次收盘的持有信息

**本轮未新增有效组件。四个首次买入日收盘条件均未支持改善H3持有；模型增量也不足以优于已有低环境的较短持有对照。** 10轮额度已使用第1轮，阶段三准备目标仍在推进。

本轮与EX007区别在首次可退出之前的决策时点、低开收阳父机会和固定H3环境，不是重复H5/10/20中点均线扫描。仅现有数据，公告暂停，费用与执行约定不变。213个已成交父机会（高153/低60），入场当天收盘观察，最早下一交易日按原H1退出；H3/H5使用相同原入场及股数。未成交不产生持有决策，没有连续账户。

| 固定风险条件 | 相对始终H3，每个已成交父机会的净现金收益变化 |
| --- | ---: |
| 修复完全抹去：入场日收盘低于信号日开盘 | −0.2272个百分点 |
| 无跟随：入场日收盘低于信号日收盘 | −0.4206个百分点 |
| 入场日股票盘中表现弱于上证同期 | −0.1677个百分点 |
| 越过前高后收于当日下半区 | −0.1813个百分点 |

前两条件嵌套，不称独立信息；第四条件不保证收在原前高之下，不称严格突破失败，也不推断最高价发生在限价成交之后。原始、去2026、按最晚退出去重及匹配结果均保留。低环境个别条件减少了延长暴露，但尚未优于更简单的整个低环境缩短持有对照，不能包装为新信号。

固定岭模型在已有浮盈、入场日波幅/缺口/盘中表现、原价格及市场状态基础上加入四条件与环境交互。H3相对简单模型平均增量+0.0922个百分点，四个决策年度点估计同正；但相对始终持有仅+0.0106个百分点，弱于仅在既有低环境选择H1的+0.3565个百分点。H5增量也未解决该问题。以上是一次独立决策探针，不能等同账户或连续退出规则。

精确现金分解解释了下一步方向：低环境H1→H3平均−1.2656个百分点，其中隔夜−0.4714、盘中−0.7943；高环境同段平均+1.0659，其中隔夜−0.9046、盘中+1.9710。高环境并未避开隔夜损失，差异主要来自盘中收益。分解只用于归因，不意味着可通过当日卖出、隔夜回补兑现，T+1和原执行约定未变。

原研究以信号年分组，本轮持有决策模型按入场/决策年分组；跨年个案会改变年度表，不改变总样本结果。环境仍使用信号年度原阈值，未追溯重判。另存信号年度归因表方便对照。

47项校验通过，包含16个年度模型独立复算、公共绑定、现金与时段分解、决策早于实际退出、嵌套条件和配对探针算术。所有结果及源码保留。阶段二目标尚未达成，下一轮优先解决原环境2020—2022和2020启动期的因果可计算性、条件信息是否保持及机会规模；不通过增加同义指标维持研究。

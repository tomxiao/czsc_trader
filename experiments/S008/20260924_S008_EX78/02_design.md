# S008 EX78 预注册设计

- 前序：EX68 receipt 必须为 `PROCEED_TO_UPSIDE_PARTICIPATION_INFORMATION_AUDIT`。EX42 日频最多两次入场 Oracle 账本、EX48 仓位/分段/差距账本及 EX16 因果面板均按固定哈希读取；不得重新优化 Oracle 或重选代表。
- 共同窗口固定为 2014-07-31—2024-12-31。预期 Oracle 有两次入场、两次退出、五段状态和四次切换。审计全部五段；将 P02（既有最高年化代表）与 P06（既有高暴露代表）并列，不按结果替换。
- 机会地图报告：每段 Oracle 状态、交易日数、全持有开盘对数收益、两代表的段内暴露与实际持有收益；总体报告 Oracle、P02、P06 的暴露、正收益捕获、负收益规避、年化收益和最大回撤。数值继承既有归档，不能解释为新回测。
- 可观测性只看四次 Oracle 切换：在执行日 T 的上一交易日 T-1 收盘，以及 T-21 的收盘，读取 EX16 因果面板的 `price_return_20d`、`gold_sge_return_20d`、`currency_usdcnh_return_20d`、`rate_us_real_10y_change_20d`。报告原值及其相对各自截至当日过去最多 252 个交易日（至少 100 个有效观测）的经验百分位。无缺失补值，缺失则保持空值。T-1/T-21 是当时已可观察的信息，但切换日期由未来最优 Oracle 事后给出。
- 禁止由四次转折的极值反推阈值、筛选因子、声称统计显著或计算候选收益。若身份/窗口/状态数不一致立即失败；若一项观察缺失仅按原值记录并披露。裁决固定为 `DISCOVERY_ONLY_OPPORTUNITY_MAP_REVIEW_REQUIRED`，下一步由用户评审目标可学性与数据需求。
- 2025 年及以后密封区不读取；不调用新的外部数据源，不设计原型，不搜索参数，不创建候选。

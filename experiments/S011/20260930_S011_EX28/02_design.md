# EX28冻结设计

- 评价：2025-02-06至2026-09-28，403交易日，初始100万元；同一原SRT实现、只做多、限价买入/市价卖出，标准单边10bp与压力20bp。
- 四个中心各47个设计位置：1个中心、7参数双向14个单项、固定持有期2天的16个六参数联合点、持有期1/3天同时变化的16个七参数联合点。共188位置，重叠参数指纹只评价一次，位置分母保留，不将重叠结果当独立样本。
- 步长：tail_weight=0.025、spx_weight=0.025、entry=0.005、exit=0.025、lookback=10、premium=0.0005、max_days=1。对应既有邻域诊断单位，未经结果调整。两种持有期分别展示，不能将离散的大幅持有期改变混称为细微扰动。
- 联合设计为16行、7个奇数奇偶性的Walsh正交列：1、2、4、8、7、11、13。每维正负各8次、每对参数四种组合各4次，包含相反符号伙伴；采用相同偏移配对比较四中心。覆盖两两方向均衡，部分高阶交互混杂，未覆盖全部二水平角点或连续区域。
- 固定设计由Optuna enqueue_trial登记，InMemoryStorage、固定种子2026093028；主进程拥有唯一Study，通过optimize最多8协调线程调度8个spawn计算进程，进程内BLAS/OpenMP及Harness workers均1。不使用自适应寻优、不因找到达标点停止、不重试失败。
- 每次公共评价启动至少间隔10秒，沿用既有DFLS接口节流。并发上限为本机16逻辑核的50%，实际并发可能受数据准备及节流限制。8进程先做无真实行情的序列化与运行时描述预检；无沙箱进程授权则先申请，不自动换后端。
- 公共REX context通过公开evaluator注入进程调度，仍由context登记capability、预算、request/result身份。新候选受管数据由公共SRT/DFLS准备，禁止复制其他候选缓存。Dataflows访问在既有用户授权范围内，不引入新数据源。
- 每个唯一参数保存完整五账本、payload、请求/结果/数据身份、worker PID、Optuna状态及提议/完成次序。中心标准账户按经济字段与旧账本核对；除ID双射外不调整数据。技术失败与经济未达标分别保留，首次技术异常结束批次并归档，后继实验承接。
- 报告按中心、联合模块、持有期及费用场景分层：原三目标各项与联合达标数量、年化/回撤/交易频率范围和分位数、相对中心退化、相同行为比例、方向均值差及配对差异。均为固定设计的描述统计，不输出总体成功概率或强加晋级阈值。
- 仍使用已见行情；本次新增评价须计入后续搜索台账。原PBO/DSR只代表旧搜索族，不能宣称覆盖本次追加试验。源码哈希保持原样，配置ID在既有666条注册快照后递增，旧ID复用；新注册快照另存以免改变旧封存包的输入字节。

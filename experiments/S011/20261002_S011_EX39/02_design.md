# EX39 设计

- 前驱 EX38 只提供当前候选技术身份。固定候选 C0621，不搜索参数，不选择其他候选；全部输入来自已授权 DFLS 数据集。
- 完整窗口一个标准成本场景，预期403个交易日。CAGR至少为限价基准1.5倍；基准非正时策略还须为正且超额；最大回撤幅度严格小于基准；60×闭合交易数÷样本交易日数在[4,6]内。
- 通过 REX FORMAL DEVELOPMENT 和 context.evaluation.evaluate 留存请求、账户、基准、指标、评价身份及执行回执；调用 TDR build_assessment_evidence 建立当前强类型评价证据。
- 平台通用 TDR run_backtest 自动增加 NextOpenBuyHold/MA 对照，与本次显式限价基准不一致，图表暂缓。先完成限价基准受管评价及账户报告；平台图表接口调整另行切换 DEV 后处理。
- 每个操作1个worker，原生计算线程4。只有1个候选/窗口/成本坐标，无独立参数任务可供多worker分配。DFLS使用现有本地缓存。
- 所有正式证据归入本实验 artifacts。技术失败保留当前证据并停止，不原地改写或重跑；负面经济结果也完整交付。
- 本轮不重建其余611个候选、不重做扰动与压力检验、不重发完整阶段三/四交付、不推进阶段五。EX38封存索引保持原文；当前评价状态通过本后继实验建立。

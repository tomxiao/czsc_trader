# S009 EX18 预注册设计

固定 EX14 P03 的 10bp 决策与同情景 BuyHold 完整账户，前序 EX14/EX17 receipt 核验。P03 决策时目标 0 代表国内流动性两窗口与政策不确定性同时非正。按决策记录顺序计算连续目标 0 日数，以该决策的 `valid_session` 匹配 BuyHold 当日账户对数收益。负状态第 1–2 日为 `EARLY`，第 3 日及以后为 `PERSISTENT`；2 日只是低复杂度机制探针，未搜索或依据真实收益选择。另保留每个负状态连续段与按年份账本。

主问题：早期负状态的错过上涨是否明显大于避开下跌，而持续负状态体现相反的风险补偿？最强竞争解释是黄金反弹、状态长度的选择效应或交易日收益随机波动；零解释是两组差异不稳定。记录每组样本数、正负收益各自对数和、净收益及逐年符号，不以任意显著性门推动新原型。只有两组在多数年度呈有意义且相反的方向，才考虑“延迟退出”完整账户后继；否则停止这个耐心持有方向。负状态内部后续天数存在留存选择，不能把其条件收益作为可执行的第 1 日预测；任何结构仍需新实现门与同口径完整账户比较。

仅读已归档 2019–2024 开发期账户/决策；不调用 DFLS、不读封存验证、不改策略或平台。合成 preflight 检查连续段编号、分组和会计恒等式。

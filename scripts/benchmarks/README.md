# 股权策略历史回放 DEV 基准

`equity_replay_benchmark.py` 对认证的 S017 EX027 三个历史账户执行 V3 等价验证。
策略夹具位于 `../../tests/support/equity_m005_v3.py`，保持 S017-M005 入场与
S017-M009、S017-M010、S017-M011 三种退出的原参数、事实解释和实际成交锚点。
这属于平台工程验收，不登记候选、不发布研究证据，也不消耗研究实验额度。

三种退出均在实际买入成交后启动持仓计数：S017-M009 等待 65 根完成柱；
S017-M010 在收盘跌破入场信号柱及其前一柱的最低价时提前退出；
S017-M011 在收盘跌破持仓期间最高完成柱收盘价减去 3 倍入场信号 ATR13 时提前退出。
后两种机制仍以 65 根为最长期限。触发后保持退出目标，直到实际清仓，
因此受阻的卖出可能在第 65 根之后才成交；未成交的买入不创建持仓周期。

从仓库根目录运行：

```powershell
$env:PYTHONDONTWRITEBYTECODE = '1'
.venv/Scripts/python.exe scripts/benchmarks/equity_replay_benchmark.py --repetitions 3
```

首次核验可使用 `--repetitions 1`，也可加 `--candidate C0048` 只核验 S017-M009。
脚本单进程运行，限制 native threads 为 1；
临时文件、源码快照、结果和身份映射均保存到唯一的
`../../.tmp/equity-replay-benchmark/` 子目录。脚本仅使用已认证的 2018 年 11 月至
2025 年末四项数据产品，2018 年部分仅用于预热；执行窗口从 2019 年首个交易日开始。
不可将该夹具直接用于其他数据合同：它明确要求所有行情柱已观察到，且可用时间等于完成时间。

验证读取历史 PreparedDataRef 和 EvidenceRef，核对内容 hash、参数、执行规格、费用、
日期窗口及四项产品身份。S999/C0001 至 C0003 仅作为内存中的 DEV 标识。
逐项比较决策、订单、成交、公司行动、逐柱账户、日账户、交易周期七张表：

- 从相同因果时间点构造决策 ID 双射，再连接订单、成交和实际买入产生的周期 ID；
  保留并核验所有外键关系，不删除 ID 字段。
- 保存规范化前的原始差异计数和样本，仅允许显式 ID 翻译及带时区时间字符串的 UTC 规范化。
- 使用旧正式账户 JSON 原有的 10 位小数序列化精度，其他数值无容差；
  解释中的数字字符串保持原样，不通过舍入掩盖差异。
- 遇到语义差异、孤儿外键、非双射或运行中源码变化即失败，并保留诊断输出；
  不能将未完成或已中止运行解释为通过。

核心时间从构造数组、TXE 初始化开始，包含特征计算、公共回放、最终七张 DataFrame 的构造；
不含 DFLS 读取、历史证据读取、JSON 序列化及比较器。报告每次耗时及三次中位数。
当前账户加载契约是：启动时装载入口模块一次，此后整段回放复用同一模块；核心不做源码身份认证。
正式调用链的身份校验由 TDR prepare 完成；本基准在核心计时前构造并校验候选，计时后复核源码未变。
统计必须满足 `source_checks=0`、`module_loads=1`；`source_bytes_read` 是账户启动阶段
实际读取的源码字节量，本夹具只有一个源文件，因此应等于该文件的字节数。
这些计数不包含基准脚本额外执行的运行前后源码快照与 hash 核验，亦不是物理磁盘读取量。
运行期间避免其他重负载任务，并保持公共核心和夹具源码稳定；
历史整轮多进程研究耗时不能直接用作该单账户核心耗时的加速比分母。

定位热点时可使用 `--repetitions 1 --candidate C0048 --profile`。
该模式仅剖析一次核心路径，输出 `.prof`、own/cumulative 各前 30 项及完整函数计数，
仍执行七表等价核验。结果明确标记 `CPROFILE_INSTRUMENTED_NOT_BENCHMARK`：
profiler 会增加耗时，不能将其耗时与未插桩的基准直接比较。

比较器的聚焦测试位于 `../../tests/functional/test_equity_replay_benchmark.py`，
覆盖允许的身份和时区变化，以及不得被隐藏的外键串接、孤儿、非双射、价格和解释差异。

## 2026-10-30 纯计算优化后的验收

本轮减少时间与标量重复转换、复用不可变解释对象，并在已认证的单调可见历史上使用
只包含过去数据的追加链；晚到数据仍沿用原有排序处理。
保持上一版本的数据、策略夹具、账户加载契约、计时边界及完整七表输出不变。
核心、夹具和脚本冻结后，在无并发测试负载下执行三种原型各 3 次，
共 9 次单进程、native threads 为 1 的无 profiler 回放。

九次七表对齐差异均为 0，受核验源码 hash 在运行前后不变；每次均执行 22,790 次决策，
并满足 `source_checks=0`、`source_bytes_read=6400`、`module_loads=1`。

| S017-M010 | 11.170 | 8.505 | 23.9% |
| S017-M011 | 11.497 | 8.955 | 22.1% |

**完整单账户核心 5 秒目标仍未达成。** 表中核心时间仍包含数据数组准备、特征计算、
